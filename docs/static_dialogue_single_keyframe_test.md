# 静态对话单关键帧测试用例

## 测试目的

验证 agent 在镜头复杂度较低时，能够根据 `visual_plan` 自主选择“单关键帧 + 导演镜头节拍表”的方式，而不是强制生成九宫格分镜。

## 给 agent 的测试输入

```text
请基于下面这个极简剧本，按当前 skills 完成编导转译和分镜表达选择。这个测试只要求做到分镜/关键帧计划，不要进入视频生成。

目标：8 秒竖屏古装静态对话片段。
场景：夜晚，茶馆二楼雅间，暖黄灯光，一张木桌，两个人面对面坐着。
角色：
- 梅冰：28岁，冷静克制，灰白色素雅长衫，声音低、冷、稳定。
- 顾行舟：30岁，温和但心虚，深蓝色长衫，声音温润、略带迟疑。

剧本：
梅冰坐在桌边，两只手揪着垂到腿上的桌布，脸色冰冷。
顾行舟坐在她对面，端着茶杯，却没有喝。
梅冰看着他，说：{你昨晚去过东院。}
顾行舟停顿一下，说：{你怎么知道？}
梅冰没有起身，只把桌布攥得更紧，说：{因为你袖口有桂花香。}

要求：
1. 这是静态对话，没有打斗、追逐、空间转场或复杂动作。
2. 允许 agent 自己选择分镜表达方式。
3. 如果选择单关键帧，需要说明为什么单关键帧足够，并写清它只负责构图、人物位置、场景和情绪。
4. 必须保留逐字对白、人物音色、手部动作“揪着桌布”、道具线索“袖口有桂花香”。
5. 输出 director_plan / storyboard 级别的结构即可，不要实际调用视频生成。
```

## 预期正确行为

- agent 应该读取或遵循 `skill_director`、`skill_movie`、`skill_prompt_engineering` 中关于 `visual_plan` 的规则。
- `visual_plan.method` 应选择 `single_keyframe`，或明确说明“单关键帧 + 导演镜头节拍表”。
- 选择理由应类似：
  - 该片段是固定场景内的静态对话。
  - 人物没有明显走位、动作推进或空间转场。
  - 主要变化来自对白、停顿、眼神、手部细节。
  - 单关键帧足够锁定构图和人物关系，动态信息由 `director_beats` 和最终视频 prompt 承接。
- 可以生成一个 `keyframe_s01_static_dialogue` 的图像计划，构图应包含：
  - 茶馆雅间内两人对坐。
  - 木桌和暖黄灯光。
  - 梅冰双手揪住垂下的桌布。
  - 顾行舟端茶但未喝。
- `director_beats` 至少应包含：
  - beat 1：建立两人对坐和紧张沉默。
  - beat 2：梅冰说 `{你昨晚去过东院。}`。
  - beat 3：顾行舟停顿后说 `{你怎么知道？}`。
  - beat 4：梅冰攥紧桌布，说 `{因为你袖口有桂花香。}`。
- `audio_plan.generate_audio` 应为 `true`，因为有逐字对白且需要原生口型。

## 不合格行为

- 强制生成九宫格，且没有说明为什么这个静态对话需要九宫格。
- 只输出一句“中景，两人对话”，没有 `director_beats`。
- 生成单关键帧后，把它当作完整动态脚本，不再保留对白和节拍。
- 丢失 `{你昨晚去过东院。}`、`{你怎么知道？}`、`{因为你袖口有桂花香。}` 中任何一句逐字台词。
- 丢失“揪着桌布”或“袖口有桂花香”这两个关键信息。
- 无对白却写了“说/询问/回答”等口型语义，或有对白却 `generate_audio=false`。

## 验证点

检查 agent 输出或调用日志时，重点看：

1. 是否出现 `visual_plan.method = single_keyframe` 或等价表述。
2. 是否没有把九宫格作为必选项。
3. 是否把单关键帧定位为构图锚点，而不是完整动态分镜。
4. 是否仍然输出完整 `director_beats`。
5. 如果后续进入视频 prompt，是否逐字包含所有对白，并设置 `generate_audio=true`。
