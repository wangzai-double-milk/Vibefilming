# Skill · Prompt Engineering（调用前最后 30 秒自检）

> **何时读我**：每次正式生成素材前。
> **我只管"这一次生成要求是否忠实继承上游方案，并被编译成可生成的画面"**。这一段戏怎么拆镜头、用哪些参考、节奏怎么排，是剧本、编导方案和故事板已经定好的事；本文件不重新规划剧情，不替代编导，只负责调用前把上游信息翻译成模型能执行的文本。

## 职责边界（先分清我做什么）

- **我继承**：剧本里的人物、事件、逐字对白/旁白、情绪动机；`director_plan` 里的镜头节拍、运镜、视角、光照、变速、画面文字、资产清单、故事板规划和段间承接。
- **我补齐**：上游已经定了大致剧情、运镜和镜头意图后，生成要求还必须补上完整画面细节：整体氛围、光影来源、空间层次、背景与前后景动态、材质纹理、空气感、环境细节、动作阶段和首尾状态。不能只写主体和动作。**编导给的情绪（如"流泪""从强忍到破防"）只是简单描述，要由我落实成“触发点→表情变化→身体细节流露”的可见链路——嘴角、眼睑、眼眶、视线、呼吸等证据；不能把"哭了/笑了"原样抄进 prompt。**
- **我不改写**：不把编导定好的机位、视角、运镜、画面文字、人物设定换成自己觉得更好看的版本；不临时发明人物外形；不把故事板当最终画风参考。
- **我不写工具层**：不规定工具名、字段名、参数默认值、文件路径和轮询方式。这里只写创作规则和生成文本质量标准。

## 调用前自检 · 命中任意一条就停手改

| 死罪 | 为什么会翻 | 正确做法 |
|---|---|---|
| **跳过参考素材** | 人物、道具、场景或分镜只写在文字里，模型会重新脑补 | 已定资产必须作为真实参考参与生成；文字只负责说明用途 |
| **故事板没用起来** | 分镜画了但没有成为视频构图和节拍依据 | 生成前确认本段故事板已经作为构图蓝图被使用 |
| **故事板画风污染成片** | 把线稿/弱色彩/草图质感继承到最终画面，成片会变成分镜草稿 | 故事板只说明大致剧情、构图顺序、走位和节拍；成片画风、光影、材质和氛围看资产参考、风格锚点和编导方案 |
| **凭空编外形** | 临时补的发型、服饰、五官会和参考图打架 | 角色外形只来自拍摄表和终版参考图，没写的别编 |
| **视觉描述只剩骨架** | 只写主体和动作，光影、材质、空间层次、前后景都让模型自由发挥，画面会漂、不稳定 | 按视觉 SOP 补齐氛围、光影、镜头视角、材质纹理、环境空气感、前后景和动作阶段 |
| **只拍主体不拍场面** | 人物是对了，但周围环境空、背景漂、前后景没有层次，像把主体贴在布景上 | 按“人物 / 背景 / 场面 / 镜头”四层补细节：主体长相与表演、空间关系、环境动态、摄影调度都要写到 |
| **角色/场景参考不足** | 角色只靠一张头像、场景只靠一张氛围图，后续视频容易换脸、换衣、空间漂移 | 主要角色先生成同图包含正/侧/背的角色卡身份母版；实际拍摄场景生成三视角/多视角空间参考包；每个镜头从同一套过审参考包里选用需要的视图 |
| **规划标注进了成片** | 把路线图里的红线、箭头、编号带进最终视频画面 | 路线/箭头/编号只用于规划参考；成片 prompt 要翻译成镜头运动和空间关系，不保留标注 |
| **主体指代漂移** | 多人物时反复写"他/她/老人/女孩"，模型容易串脸或生成重复人物 | 先给每个主体稳定标签，后续动作、对白、位置都用同一标签 |
| **对白丢失或概述化** | “他说了几句”无法生成准确口型和情绪 | 逐字台词、说话人、音色和情绪必须完整保留 |
| **声音意图矛盾** | 有口型但没台词、有配乐但没说明、不想要配乐却没禁用 | 声音计划必须明确：对白、环境声、配乐、静默分别是什么 |
| **用文字修参考图缺陷** | 参考图本身错，后续会继续污染 | 回到素材环节修参考图，不靠文字反向补救 |

## 一、先消费故事板/拍摄表，别自由发挥

如果当前项目已经产出了结构化拍摄表（如全片计划、片段表、镜头节拍、音频计划、故事板），那么最终生成要求**不能自由改写，必须按拍摄表逐项编译**。这是调用前第一道闸门。

消费顺序要清楚：先看 `director_plan` 中本段 beat、镜头语言、资产清单、画面文字和故事板职责；再看剧本里的逐字台词/旁白和人物动机；最后看实际可用的终版参考素材。三者冲突时，先停下来校准，不要在 prompt 里混写两套设定。

逐项消费规则：
- **镜头节拍**：按顺序展开，不跳节拍、不把关键节拍合并成一句概述。
- **主体定义**：多主体镜头先定义每个主体的稳定标签和对应参考来源；后续每次写动作、表情、对白、站位都用同一标签，不用"他/她/那个人"这种可被误绑定的代词。人物身份本身**没有新的特殊符号轨**，不要发明 `[]`、`<>` 之类把人物包起来；用稳定名称/代号反复指代即可。只有人物首次出场旁边的人名牌、身份牌这类**画面文字**才用 `【】`。
- **对白/声音**：逐字抽取台词，写明说话人、音色、情绪和说话时机；同一角色每段都重复完整音色，不写"音色同上"。
- **画面内文字**（屏幕/纸条/手机/日历等画面里的字，以及编导设计的片名/人名牌/段落/时间地点卡这类标题标识短文字）：每处逐字写出，并安排成清楚可读的镜头，不要写"出现一行行文字""弹出提示"。如果 plan 给这处文字设计了出现/消散时机和引入引出动效（如人名牌停 1–2 秒后淡出、片名卡在钩子后引入、镜头内某段时间出字再淡出），把**逐字内容、在这一镜的哪个时间段出现、停留多久、何时消散、用什么动效与位置、样式与全片风格如何一致**一并编译进生成要求，别只写"加个标题"或"加个字"。该上不该上由编导方案判断，本步只负责把 plan 已定的忠实落下来；整段对白/台词字幕不做。
- **关键信息/动作破绽**：每条对应一个明确镜头或特写，不写"发现异常""感觉不对"。
- **音效、配乐和旁白**：写具体声音事件和音乐意图，不写"气氛紧张"这种无法执行的氛围词。没有角色对白的剧情片，也要有清楚的声音叙事方案；除非用户明确要求纯音乐或无声，否则用旁白、画外音、环境声和音乐承担信息推进。
- **故事板/分镜图**：它只说明本段的大致剧情推进、构图顺序、主体走位、镜头节拍和动作方向，必须真实参与本段生成；不能只在文字里说"参考故事板"。故事板必须是多宫格/多面板的手绘草图（线稿/弱色彩）表达，能看出镜头顺序、主体走位、动作变化、情绪或信息递进；复杂动态、强反转、多关键信息点的戏，不许只靠一张静态氛围图硬生。故事板的手绘弱色彩是有意为之——颜色、外观、光影、材质、氛围和最终质感由资产参考、风格锚点和编导方案决定，别把故事板的线稿风格当成成片画风继承。
  - ⚠️ **写故事板生成要求时的硬红线（这一步最容易跑歪）**：你正在写的是去生成一张"故事板图"的 prompt，不是去生成成片。动笔前确认这条 prompt 里——① 明确要求"多宫格/多面板（multi-panel）、每格一个镜头、格间有箭头/标号表示顺序"；② 明确要求"手绘线稿/铅笔速写/弱色彩（hand-drawn sketch / line art / storyboard panels）"；③ **绝不出现**"电影级写实渲染 / photorealistic / cinematic / 精细上色 / 成片质感"这类词——这些词会直接把故事板生成成漂亮的写实单帧，是已发生过的真实事故。如果你写出来的故事板 prompt 和"生成一张成片画面"的 prompt 长得几乎一样（单帧、写实、满色彩），就是写错了，回去改成多宫格手绘线稿再调用。
- **故事板元素必须有资产支撑**：故事板只决定故事怎么推进、镜头怎么排、元素在画面中如何出现；角色、场景、关键道具的具体外观、材质和风格必须来自终版资产参考。生成本段视频前确认：故事板里出现的角色、场景和关键道具，是否都有对应资产参考一起参与；缺哪个就回素材环节补，别让模型仅凭故事板外观脑补。
- **分清故事板和画风锚点**：带故事板做视频参考时，故事板只控制构图、顺序、走位、动作方向和节奏；画面风格、材质、光影、细节由角色/场景/道具参考和全片风格锚点决定。最终生成要求必须把这两类参考的职责分清，避免把故事板的视觉质感误当成成片画风。
- **故事板边界必须写进视频 prompt 正文**：只要本段视频使用故事板作为参考，最终生成要求里就要显式出现这层意思——故事板只作大致剧情、构图、走位和节拍参考；最终画面不继承线稿、弱色彩、草图质感或简化外观，成片质感按角色/场景/道具参考、风格锚点和编导方案呈现。可以换表达，但不能省略；只在心里知道、只在上游 plan 写过、最终 prompt 没写出来，都不算通过。
- **参考素材取舍**：只使用本镜头真正需要的角色、场景、道具、构图或声音参考。参考越多越容易互相抢权重；不相关素材会制造身份、风格和空间冲突。
- **统一参考包编译**：角色卡、场景多视角、风格锚点、关键道具和故事板要作为同一套全片参考体系被消费。写 prompt 前先确认本镜头使用哪个角色参考包、哪个场景参考包、哪张故事板；文本里说清每张参考的职责：角色卡锁身份和服饰，场景参考锁空间与光影，风格锚点锁全片质感，故事板锁构图和节拍。不要临时拿一张新图替代已过审参考包。

编译完做一次字符串级核对：拍摄表里每句对白是否以 `{}` 声音/台词形式逐字进入生成要求，每句画面内文字是否以画面文字形式逐字进入生成要求；**对白不要塞进 `【】` 当画面字幕，标题标识类短文字才用 `【】`**。本段故事板和终版参考资产是否真的被使用。缺一项就不许调用。

## 二、图像/视频视觉描述 SOP（把上游方案编译成可生成画面）

生图和生视频都不能只写"主体 + 动作"的骨架。最终生成要求必须先消费 `script.md` 和 `director_plan`：剧本给人物、情绪、事件、关键道具和声音动机；director_plan 给全片风格锚点、分段影调、镜头节拍、画面文字、资产清单、故事板职责、光照/视角/运镜/焦点/变速等导演选择。**上游已经写明的视觉信息要继承；上游没写明但这一镜要成立所必需的细节，可以按情绪和风格补齐；补齐不能覆盖上游已经定好的设定。**

每次生成前，先判断这次产物服务什么：人物/道具/场景/风格锚图、关键特写参考、故事板图、运镜路径参考，还是最终视频镜头。不同产物的文本密度不同，但都要按下面这些维度自检，按需写清，不要用空泛词糊过去：

- **整体氛围与风格一致性**：写清这张图或这段视频处在全片哪个情绪阶段，影调是压迫、舒展、冷静、温暖、危险、荒凉还是明亮等；色彩、明暗反差、颗粒感、干净程度、商业感或纪实感要和全片风格锚点、当前段落情绪一致。不要只写"高级感""电影感""科技感"，要把它落到色温、饱和度、明暗关系、画面干净度和空间气质上。
- **光影**：写清主要光源从哪里来、光的方向、高低、软硬、冷暖、强弱、明暗反差，以及光打在主体哪一侧、背景和地面留下什么层次。视频镜头还要把 director_plan 里的光照节拍编译成镜头内可执行描述：这几秒是什么光、从哪个方向和高度打过来、什么时候被人物/门窗/道具遮挡或变化。光必须有画面内动机或风格动机，不能每张图随机换光。涉及反射、透光、阴影、轮廓光、屏幕光、自然光或人工光时，要写清它们如何影响主体、材质和气氛。自然光必须和时间自洽：清晨/黄昏是低角度暖斜光，中午更接近顶光且更硬，夜晚靠月光、灯笼、火光、屏幕光或室内灯，不要写出和故事时间冲突的太阳方向；室内窗光要写窗在哪一侧、光从哪侧落到脸、墙、地面。
- **镜头与视角**：图片也要有构图和观看角度，视频更要继承 director_plan 的景别、机位视角、运镜方向与速度、稳定度、焦点景深和变速。视角不能泛化成“电影感镜头”或“好看的角度”，要写成可执行机位：第一人称仰拍/俯视、第三人称斜后方跟拍、过肩半主观、无人机俯瞰、贴地视角、门缝/柜内/冰箱内部的物体主观视角等，并说明镜头在主体的前/后/侧/高/低哪个位置。资产母版类图片优先清楚稳定、便于锁一致性；镜头特写类图片和视频镜头则要继承对应 beat 的视角、景别、光照和焦点，不要把导演已经选好的镜头语言改成泛泛的"好看画面"。
- **空间层次**：写清前景、中景、后景分别承担什么，主体在哪一层，哪些元素清晰、哪些元素虚化、哪些元素只是环境动态。需要浅景深或背景虚化时，要说明虚化服务什么信息和注意力；不需要时不要为了好看滥用虚化，尤其不能让关键道具、屏幕文字或信息线索被虚掉。
- **空间朝向与运动方向**：这是最容易被漏掉、也最容易让画面漂的一维，必须显式写。① **主体朝向**：人物/物体面朝哪个方向、正对镜头还是侧身/背对、视线看向画面内哪个点或哪个方向；不能只写"一个人站着"。② **运动方向**：主体是朝画面里/画面外、向左/向右、向前（冲镜头）/向后（远离镜头）、向上/向下运动，以及镜头相对主体是跟随、迎面、侧移还是后退；"往前跑"和"往后退"是完全不同的画面，必须点明。③ **主体与环境的空间关系**：主体在场景里的位置（街道左侧/广场中央/楼梯顶端）、和关键地标/其他人物的相对方位（在灯楼下方朝城门方向、背对人群面向江面）、进出画面从哪条边进哪条边出；进房间/出房间/过门/转角要写清入口在画面哪侧、门内外的空间关系、人物从哪边进到哪边。④ **人物之间的视线与站位**：两个人分站画面两边时，要写清 A 在左还是右、B 在左还是右、谁看向谁、视线穿过画面哪个方向，避免两人站位和眼神互相打架。⑤ **镜头相对空间的位置与角度**：机位在主体的正前/侧/后/高/低，观众是俯视还是仰视这个空间。空间信息要和 director_plan 的机位、运镜方向一致，不能让人物无缘由地转向或运动方向和镜头运动打架。
- **跨镜头空间连续性（越轴/方向一致）**：相邻镜头衔接时，同一主体的朝向和运动方向要保持一致的画面方向逻辑，不能上一镜向右跑、下一镜无解释变成向左跑（越轴会让观众瞬间迷失空间）。追逐、对话、行进、进出场景这类有明确方向的戏，要在相邻两段生成要求里写清主体从哪边进、朝哪边去、镜头在轴线的哪一侧；确实需要换方向时，用转身、转场或过轴镜头交代清楚，别硬跳。
- **材质与纹理**：所有需要观众看清或感到质感的物体、地貌、服装、皮肤、毛发、屏幕、纸张、金属、玻璃、液体、尘土等，都要写清材质类别、表面状态、粗糙/光滑、干湿、颗粒、磨损、折痕、反光/吸光/透光、边缘和尺度关系。特写镜头更不能只写物体名称；镜头越近，纹理、边缘、接触面和细节越要具体。**写实真人质感靠"有瑕疵"而不是"尽可能光滑细致"。** 追求真实人像时，皮肤要写出毛孔、细纹、汗毛、皮肤油光不均、轻微色斑/痘印/晒痕、唇纹、眼下细纹、次表面散射（光透进皮肤的微红感）这类真实瑕疵；过度磨皮、零毛孔、蜡像般均匀的"完美皮肤"反而一眼假。别只写"皮肤细腻光滑"——那是塑料感的根源。同理真实布料有褶皱起球磨损、金属有划痕氧化指纹、木石有磕碰、玻璃有灰尘水痕。（唯美/广告/动画/古风写意等非写实风格按各自既定调性走，不必硬塞瑕疵。）
- **质感四层（图像和视频都适用）**：不要把质感压成“高清、电影感、细节丰富”。按这一镜真正需要的层次补：① **环境层**：空气悬浮物、雾/烟/尘/雨丝、湿度、体积光、热浪、远近空气透视，说明它们如何让空间有厚度；② **镜头层**：感光颗粒、景深、焦点转移、前景遮挡、镜头眩光、bloom/halation、运动模糊，说明它们如何控制注意力；③ **材质层**：物体和皮肤的粗糙度、油光、反射/吸收/透光、磨损、指纹、水痕、接触面和边缘尺度；④ **显影层**：色彩倾向、阴影密度、明暗对比、饱和度、黑位、高光保留、冷暖分离。四层不是每次全堆，而是选本镜最能服务情绪和信息的几层写清；图像同样要写，视频还要写这些质感如何随动作/光线变化。
- **环境与空气感**：场景不是背景板。写清地面、墙面、天空、空气、湿度、烟尘、雾气、风、热浪、漂浮颗粒、反射和环境运动是否存在，以及它们如何服务情绪和空间真实感。环境动态要克制服务主体，不要堆到抢戏。
- **前后景动态**：视频里主体之外的画面也要有导演控制。前景有人物说话或关键动作时，后景可以有被虚化但方向明确的移动、光影变化或环境活动；后景承担信息时则要让焦点、景深和构图把观众视线带过去。不要让背景随机乱动，也不要把所有层次写成静态布景。
- **动作与时间推进**：视频要写清镜头内从起点到落点的变化，包括主体动作、表情变化、身体重心、次级运动、环境响应、开头状态和结尾状态。图片如果是关键动作或特写参考，也要写清它捕捉的是哪个动作阶段、要让后续视频看清什么。
- **信息优先级**：先保住这一镜必须传达的信息，再加质感。关键文字、屏幕、道具线索、人物表情、决定性动作不能被氛围细节、背景虚化、炫光、复杂装饰或过多参考素材盖住。

### 审美细节密度编译

如果 `director_plan` 把某个 beat 设计成高密度审美镜头，或者这一镜天然属于人物首次重要出场、情绪特写、关键道具/产品/屏幕/文字特写、场景母版、高潮动作、反转揭示、情绪峰值、片名/章节/时间地点卡，那么最终生成要求不能只写剧情摘要和动作摘要。它必须把“为什么好看、为什么有故事感”写成可生成的画面证据。

编译时按下面九类抓手取舍，至少覆盖这一镜真正需要的几类；不是机械全写，也不是固定模板：

- **人物可见状态**：把抽象情绪翻译成脸、眼神、嘴角、呼吸、手指、肩背、汗、泪、血、发丝、衣褶和小动作。少写“绝望的破碎感”这种单独形容词，必须补出破碎感长在哪里。**编导只会给一个简单的情绪、触发点和变化方向（如"听见旧案后从强忍到破防"）——PE 必须把它落实成可见链路，不能把编导的"哭了/笑了/流泪"原样抄进 prompt。** 写情绪时按“触发→压住/动摇/失守→外部流露”展开：先说明哪件事触发了情绪，再写视线、眼睑、眼眶、嘴角、下颌、呼吸、手指或肩背如何一步步变化。重点不是哭得多，而是变化有没有原因、有没有过程。"流泪"要拆成：触发后眼神先失焦或躲开、眼眶泛红发热、睫毛颤动、泪水在下眼睑打转聚成一颗、顺着哪一侧脸颊滑落、滑到下颌是否停顿再滴落、嘴角是抿紧强忍还是失守下压、呼吸是否哽住肩膀微耸。同理"微笑"要拆成触发原因、嘴角上扬幅度、是否露齿、眼尾是否弯起有细纹（真笑连眼睛一起笑）、脸颊是否上提、酒窝是否出现。把眉头、眼睑与睁合度、瞳孔与视线落点、鼻翼、嘴角弧度与松紧、下颌与咬肌、脸颊肌肉、颈部线条、呼吸起伏这些可见部位分别写清，并写出它们**在这一镜里如何随情绪推进变化**。“微笑/悲伤/惊讶/愤怒/流泪”只是结果标签，必须落成脸上具体能拍到的肌肉与神态证据；越是情绪特写和近景，脸部微表情越要具体到能让审片看清。
- **叙事道具与环境证据**：写清哪些道具、残留痕迹、屏幕内容、破损物、雨水、脚印、血迹、灰尘、倒下的物件在替故事说话；背景不是装饰，要暗示前因后果。
- **主光与色彩反差**：写清主光来源、方向、冷暖、软硬、明暗反差和关键色彩爆点。不要只写“电影感光影”；要写月光、火光、屏幕光、体积光、逆光、轮廓光分别照到哪里，哪种颜色压住画面，哪种颜色负责情绪冲击。
- **摄影注意力**：写清观看距离、景别、视角、焦点落点和景深服务什么信息。可以用镜头语言或等价光学描述，如焦点锁在睫毛泪珠、手指和玉佩接触面、裂缝冷光、鱼背踩踏点；使用 85mm、f/1.8、超广角、长焦压缩、微距等说法时，必须是为了控制注意力，不是为了装专业。
- **材质微细节**：镜头越近，越要写清皮肤、布料、金属、石头、木头、纸张、玻璃、液体、沙尘、雨丝、血液等的干湿、粗糙、磨损、颗粒、反光、透光、粘稠、边缘和接触面。**真人皮肤特写尤其要写瑕疵而非光滑**：毛孔、细纹、汗毛、油光不均、次表面散射、轻微色斑/痘印、唇纹、眼周细纹——这些才是"真"，磨皮到零毛孔的完美皮肤在近景里反而最假。
- **整体质感分层**：高密度镜头还要说明质感主要来自哪一层：环境层的空气悬浮物/空气透视，镜头层的感光颗粒/景深/光效，材质层的物体与皮肤反射，显影层的色彩/阴影/对比度。不要把这四层混成一句“质感真实”；要写出本镜哪一层最重要、它如何服务情绪和信息。
- **空间层次**：前景、中景、后景分别放什么，主体处在哪一层，哪些元素清楚、哪些虚化，背景是否有方向明确但不抢戏的运动。大场景要写出尺度、地形、入口/路径、建筑层级和观众视线如何穿过空间。还要写清主体在空间里的**朝向和运动方向**：面朝哪、看向哪、往画面里还是画面外、向前冲还是向后退、从哪条边进哪条边出，以及和关键地标/其他人物的相对方位——方向感缺失是这类镜头最常见的漂移源。
- **环境空气感**：雾、烟、尘、雨、雪、热浪、漂浮颗粒、反射、湿度和风怎么作用在人物、道具和光线上；这些只能服务情绪和空间真实，不能堆成杂乱背景。
- **动作物理与环境响应**：高潮动作要写清接触点、受力、惯性、落点和环境反应，比如脚踩鱼背的压陷和反弹、水花方向、衣摆滞后、身体重心变化；否则动作会变成“发生了但不好看”。
- **风格质感与世界观纯度**：风格名、导演名、电影名只能当方向，必须翻译成可见条件：画幅、颗粒、色彩、明暗、镜头稳定度、质感干净或粗粝、时代/世界观禁忌。古风要排除现代建筑、现代标识和不合时代材质；商业、科幻、现实题材也要守住各自的视觉纯度。

反过来，下面这些写法不够：只写“古风美人很悲伤”“史诗级古城”“电影级质感”“高对比度”“8K 超清”“画面震撼”。这些词可以作为结果方向，但不能替代可见证据。高密度镜头的 prompt 应该让人不用看剧本也能想象画面：谁在画面里、她的状态长什么样、周围哪些东西在讲故事、光从哪来、焦点在哪、材质和空气如何把情绪变成质感。

按生成类型落地时，再做一次取舍。这里不是固定模板，而是编译时的检查清单：

- **人物/角色参考图**：主要任务是锁住稳定身份。主要角色默认生成一张角色卡/character sheet：同一张图里清楚摆出正面全身、侧面全身、背面全身三视图；需要表演或近景时可在同图或补充图里加入面部近景、表情基线、手部/服饰/关键配饰细节。角色卡要清楚、稳定、少背景干扰，写清脸型、五官比例、眼神气质、发型发色、肤色与皮肤质感、身材骨架、年龄感、服装轮廓与配色、关键配饰；不要为了戏剧效果把人物遮暗、裁切、藏进复杂背景。**写实真人角色的皮肤质感要写成有毛孔、细纹、汗毛、真实肤色不均的活人皮肤，别要求磨皮、无瑕、瓷肌**——参考图一旦定成塑料完美脸，后续所有镜头都会继承这份假。人物声音、说话习惯属于视频/声音编译时继承，不靠静态图解决。
- **道具 / 产品 / 局部资产**：写清物体形状、尺度、材质、边缘、磨损、反光/透光、使用痕迹、品牌或剧情必须看清的文字。枪械、手机、电脑屏幕、UI、纸条、产品包装、手部动作道具这类信息物，优先保证可读性和结构正确，不要只写一个名字。
- **背景 / 场景参考**：场景不是氛围词。实际拍摄场景默认生成三视角/多视角空间参考包，写清空间结构、入口/出口、主体常站位置、前中后景、地面/墙面/天花/窗/光源、主要材质、色彩和光影基准。简单房间、桌面、街角、车内也要有主视角/入口视角、侧向或反向视角、俯视/平面总览或关键区域视角。复杂空间按计划升级为参考组：总览/俯视或鸟瞰、主视角、关键区域/地标、路线关系、材质光影基准。
- **场面 / 群像 / 大动作参考**：写清规模、主体与次要人物的位置关系、运动方向、前景遮挡、背景活动、环境响应、危险源或视觉重心。场面不是“很多人在做事”，而是观众先看谁、再看哪里、动作如何从一个焦点传到另一个焦点。
- **运镜路径参考图 / 动线图**：用于说明镜头和主体在复杂空间里的路线。可以用简化场景、箭头、红线、起点、终点、节点和焦点标注把路径说明白；这些标注只用于规划，不属于最终画面。编译成视频生成要求时，要翻译成“镜头从哪里开始、如何移动、跟随谁、经过哪些节点、在哪里停顿或转向”，不能让红线、箭头或编号出现在成片里。
- **关键特写参考图**：主要任务是让观众将来在视频里看清一个局部、一个信息、一个材质或一个动作细节。主体要占画面足够大，纹理、边缘、接触面、手指/屏幕/纸张/金属/液体等细节要具体；如果它承载文字或屏幕内容，逐字内容、排版区域和可读性优先于氛围。
- **故事板图**：只负责大致剧情推进、构图顺序、走位、动作方向和节拍关系。写故事板 prompt 时走手绘多宫格规则；把它拿去做视频参考时，只继承故事流动、构图和节拍，**绝不继承故事板的线稿画风、弱色彩、草图质感或简化外观**。
- **视频镜头**：主要任务是把 `director_plan` 的 beat 拍出来。编导给了运镜、视角、氛围方向和大致剧情后，生成要求要继续补完整画面：人物外形与表演、前中后景、镜头运动、焦点变化、光影变化、环境动态、材质质感、首尾状态和段间承接。不要只写“Alex 看着屏幕微笑”；要写屏幕光如何打到脸上、桌面有哪些不抢戏的细节、背景如何虚实、人物表情如何从紧绷到松弛、镜头如何推进到落点。

## 三、Seedance 特殊符号（这是 prompt 语法，不能删）

Seedance 会靠特殊符号识别音频和文字意图。这些不是工具参数，而是生成要求本身的一部分：

| 内容 | 符号 | 规则 |
|---|---|---|
| 音乐 / BGM | `（）` | 需要配乐时写清音乐情绪、强弱、节奏和对白避让；不需要配乐时明确写无背景音乐。 |
| 音效 / 环境声 | `<>` | 写具体声源和动作声，不写"气氛紧张"这类抽象氛围词。 |
| 台词 / 实声对白 | `{}` | 有人物开口、口型、说话、喊叫、低语等语义时，必须写逐字台词；只写"他说/她嘴唇微动"不够。 |
| 旁白 / 画外音 / 内心 OS | `{}` | 需要生成声音时也必须写逐字文本，并说明它是画外音/内心 OS、人物不张嘴或不查口型。 |
| 标题标识 / 画面文字 / 屏幕叠字 | `【】` | 只用于编导设计的标题标识类画面文字——片名/剧名卡、人名牌、段落/章节标题、时间/地点卡。逐字写清内容，并把出现/消散时机、引入引出动效、位置和样式一起带上（见下文"画面文字与动效"）。plan 没设计画面文字就不要写；**对白/台词永远不用 `【】`，整段对白/台词字幕不做**。画面内道具文字（屏幕/纸条等）仍要逐字写清。 |

硬规则：出现说话语义但没有 `{逐字台词}`，就会变成嘴动无声或含混噪声；需要声音但没写对应符号，模型很可能不会按预期生成。

使用边界：
- `{}` 只放真正要生成出来的人声文本。`{无对白}`、`{沉默}` 这类不是台词，会误导模型；无对白应写成普通约束：无人物说话、无旁白、无口型，只保留指定环境声或静默。
- 有对白时，不只写台词本身，还要按拍摄表写清说话时机、语速/情绪、停顿和结尾余韵；需要被打断、急促说完、慢动作留白都可以，但必须明确写成创作意图，不能让模型自己猜。
- 段尾有对白时，生成要求里要说明最后一句结束后是否留反应镜头、呼吸、停顿或环境声收束，避免尾音贴着段边界。
- **对白和画面文字分轨**：对白、旁白、画外音只进 `{}` 作为声音，不额外生成同文字幕；标题、人物名牌、章节/时间/地点卡这类短标识才进 `【】` 作为画面文字。看到台词时先问“这是不是人物/旁白要说出来的话”：是，就用 `{}`，不要再复制一份到 `【】`。
- **画面文字与动效**：`【】` 里的标题标识文字不是写完内容就完事——plan 给它设计了动效就要把动效一起编译。写清这处文字**在这一镜的哪个时间段出现、停留多久、何时消散**（用镜头内时间段表达，不写死精确帧）、**用什么引入/引出动效**（淡入淡出 / 上滑 / 打字机 / 缩放等）、**在画面什么位置**（居中片名、角色旁 lower-third、角落时间卡等）、**样式与全片风格如何一致**（字体气质、颜色、描边/底色随剧集整体调性走）。文字要短、行数克制，长了模型必乱码截断；该上不该上、内容/时机/样式以 plan 为准。
- **高风险文字先降复杂度**：长 URL、带连字符的路径、emoji、复杂标点、过长中英混排最容易被画错、漏字或截断。必须放进画面时，优先改成短域名/短口号/短标签，或拆成多次出现；不要把一整串地址、长句或 emoji 标识塞进同一行还要求一次成片。画面文字承载 CTA 时，宁可短而清楚，也不要长而不可读。

## 四、生成要求怎么写

- 先明确任务类型：新生成、基于参考改写、延展已有内容、局部替换。不要把几种意图混成一句含糊描述。
- 多主体场景必须给每个主体稳定标签，后续每次动作、对白、位置变化都指向具体主体，避免串脸和错人。
- **描述靠前先把主体身份钉死，再展开动作、场景、镜头。** 视频生成最容易崩在"主体识别"——主体压到一句话最后才交代，模型读到一半才知道画面主角是谁、已经把算力分给了场景元素。所以一镜的生成要求先交代主体是谁、长什么样（稳定标签接参考），再写它在做什么、在什么场景、用什么镜头。这是软原则不是死格式：不必强行套固定段式，镜头语言、首尾镜、光照这些该写在哪还写在哪；意思只是别让主体后置。
- 描述角色外形只允许来自两个来源：拍摄表已写明的稳定特征、终版参考图实际呈现。两者都没说的细节不要临时脑补。
- 多张参考图同时参与时，要在文字里说清每张各自负责什么，别让模型平均地把所有参考的画风都揉进来。典型分工：角色/道具/场景参考负责"长什么样"（外形、材质、配色、身份特征），风格锚图负责"整体调性/光影/质感"，故事板负责"故事流动、构图与镜头编排"。只要故事板作为视频参考进入生成要求，就要显式写清：**故事板只作大致剧情、构图、走位和节拍参考；最终画面不继承线稿、弱色彩或草图质感**。成片画风以资产参考和风格锚图为准，不继承故事板自身的视觉风格。
- **画面细节按第二节的视觉 SOP 补齐，别只给骨架。** 在不跑偏主体和镜头设计的前提下，把整体氛围、光影、镜头视角、空间层次、材质纹理、环境空气感、前后景动态和动作阶段写具体。细节必须服务这一镜的情绪和信息，不要堆砌与剧情无关的杂物，也不要细到喧宾夺主盖过主体或破坏镜头语言。
- **高密度审美镜头要按“可见证据”写，不按形容词写。** 编导已经标出人物出场、情绪特写、关键道具、场景母版、高潮动作、反转或情绪峰值时，生成要求必须显式写出人物可见状态、叙事物证、光色反差、摄影焦点、材质空气、空间层次和世界观纯度中与本镜相关的项。不要把这些压缩成“质感拉满”“电影级”“绝美”“史诗氛围”。
- **有表演或动作变化的镜头，要写出镜头内推进，别只给一个静止状态词。** 单写"哭""害怕""愤怒"不够，要写清这一镜里是什么触发了变化，表情、身体和动作如何从起点变化到落点。固定机位、靠表演撑住的单镜、长镜头、复杂运镜或关键特写，更适合按前段/中段/后段说明情绪曲线：前段是什么状态，哪个事件/台词/物件触发中段变化，后段落到什么表情或动作。简单空镜和极短反应不必硬拆时间段，但动作仍要有起势、过程和落点。节奏用镜头内阶段关系表达，不用精确秒点替代导演节拍。
- 动态描述按镜头顺序展开主体动作、空间变化、声音。可以写"镜头 1/镜头 2/镜头 3"这种时序分镜，但不要用过细时间戳替代镜头节拍；模型对精确秒点不稳定，节奏靠镜头和动作承接表达。（注意这是镜头内动作的时间排序，和上面"主体身份靠前钉死"不冲突：先交代主体是谁，再按镜头顺序铺动作。）
- 镜头语言要写进生成要求，不能丢。编导在 beat 里已经为这一镜的景别/明确视角类型/机位/运镜方向和速度及稳定度/焦点景深（前景背景虚实、焦点是否转移）/光照来源、角度、性质与时间合理性/变速逐个维度选定了具体选项，**编译时要把这些已选定的选项照搬落进 prompt，不许在这一步泛化或丢维度**——编导写"第一人称低角度仰拍、镜头在门槛内侧缓慢推近、手持轻晃、窗外清晨低角度侧光45°打到右脸、关键动作升格"，就要在生成要求里把这几样都写出来，不能压缩成"一个有张力的镜头"或只挑一两样写。编导没有指明的维度可以按这一镜的情绪合理补，但不能反过来把编导明确选定的覆盖掉。并用文字暗示首尾镜（opening frame / ending frame）。不要把一段戏写成全程一个固定景别、一种平移；编导设计的镜头变化和递进要照搬，不能在生成要求里被抹平成"拍一下人物做动作"。
- **编导设计的变速（慢镜头/升格、加速/降格）要编译进生成要求。** plan 里写了变速的镜头，就要写清哪个动作或哪个节拍使用慢动作、加速或回到正常速度，以及这样处理服务什么情绪或信息。变速是表达手段，不写清就容易被默认成普通速度，关键瞬间会被一带而过。
- 动作要具体到可见身体部位、速度、幅度和惯性承接。少写"非常悲伤/很紧张"，改成低头、肩膀微颤、手指攥紧衣角、频繁看表、呼吸急促、眼神闪躲这类可拍细节。
- **动作和调度必须带明确的空间朝向与方向。** 任何走、跑、转身、伸手、跌倒、进出场景都要写清朝向（面朝哪、看向哪）和方向（往画面里/外、向左/右、向前冲镜头/向后远离、从哪条边进哪条边出），以及主体和场景关键地标、其他人物的相对方位。别写"她跑起来""他走过去"这种没有方向的动作——"往前跑（冲向镜头）"和"往后跑（远离镜头奔向城门）"是两个完全不同的画面。相邻镜头里同一主体的朝向和运动方向要保持画面方向一致（别无解释越轴），需要换方向就用转身/转场交代。镜头运动方向也要和主体运动逻辑对齐，不能人物往前而镜头无故后拉造成方向打架。
- 优先写低缓、连续、可追踪的小动作；除非剧情需要，少把单段写成狂奔、大跳、剧烈翻滚等高爆发动作。高动态动作要拆清楚起势、过程和落点。
- 台词语言统一，专有名词除外；同一角色的音色和说话习惯保持一致。
- 有人物开口就必须有逐字台词并使用台词符号；不需要台词时，把动作改成纯表情或动作，避免“嘴动无声”。
- 段间衔接要写进生成要求：开头承接上一段的情绪/动作/声音/未完成信息，结尾把下一段需要接住的情绪、目标或悬念留出来。`director_plan` 已经设计了首尾镜咬合、声音桥、叠化、黑场、淡出淡入或硬切节奏时，要把对应的画面起止状态写清楚；例如上一段末尾要慢慢暗下去、下一段要从暗部慢慢显现，就在相邻两段的生成要求里分别写出结尾淡下去和开头显现的画面状态。不要只写本段孤立画面。
- 文字保持聚焦，别把完整剧本、审查记录和无关设定全塞进去。信息太多会分散模型注意力；无关背景放回上游计划，最终生成要求只保留本镜头必须执行的内容。
- 配乐是导演决策：需要就写清情绪、强弱和对白避让；不需要就明确禁用。不要让模型随机决定。

## 五、不要写工具层内容

- 不在 skill 里规定具体工具名、字段名、参数默认值、文件路径写法、任务轮询方式或底层滤镜。
- 不把工具已经承载的参考输入，在文本里反复复述成“参考某某文件”；文本只说明每个参考素材的叙事用途。
- 不写固定模板。特殊符号是模型可识别的 prompt 语法，必须按需使用；但不要把整段生成要求做成僵硬模板。
- 不用一段通用样板套所有镜头；短片、广告、口播、空镜、动作戏的文本密度和声音意图应随内容变化。

## 六、最后放行条件

正式调用前逐项确认：

- 逐字对白没有丢。
- 画面内文字没有丢。
- 关键动作和反应没有被概述掉。
- 本段故事板已经真实参与生成。
- 生成要求已经显式写清故事板只管大致剧情、构图、走位和节拍；没有把故事板的手绘线稿、弱色彩或草图质感当成成片画风继承。
- 本段涉及的角色、场景、道具参考已经真实参与生成；场景三视角/多视角参考组、运镜路径图等空间参考也已经按 plan 参与编译。
- 图像/视频生成要求已经按视觉 SOP 补齐氛围、光影、材质、空间层次、前后景和镜头语言。
- 有动作或调度的镜头已经写清主体朝向、运动方向和与场景/其他人物的空间关系；相邻镜头方向一致没有无解释越轴。
- 靠脸传情绪的镜头已经写清触发原因、情绪推进和微表情级外部流露（眉眼、嘴角、下颌、视线、呼吸等可见证据及其推进变化），没有只写"微笑/悲伤/惊讶"这类结果标签。
- 画面质感已经按环境层、镜头层、材质层、显影层选择并落成可见证据；没有只写“电影感/高清/质感拉满”。
- 若本段是人物出场、情绪特写、关键道具/场景母版、高潮动作、反转或情绪峰值，生成要求已经按审美细节密度规则写出可见证据；没有只靠“电影感/绝美/史诗/8K”等结果词撑质感。
- 音频意图没有自相矛盾。
- 没有临时新增人物外形设定。
- 没有把工具层字段、参数、路径、模板写进 skill 规则。
