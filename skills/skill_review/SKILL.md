# Skill · 审查（看片人的标准）

> **何时读我**：每一次要对生成出来的图像或视频做质量判断之前。审查是一道独立关卡，和"把东西做出来"是两件事。

## 核心立场
做审查时你不是急着往下走的制作者，而是**第一次看到素材、立场中立、专挑毛病的看片人**。制作者总倾向于认为自己没问题，所以要刻意切换到挑剔视角。但"挑剔"不等于"吹毛求疵"——审查的目的是**拦住真问题、放过不影响观感的小瑕疵**，不是追求完美而无限重做。

**别诱导自己放行**：审查问题里不要写"已知通过""轻微瑕疵已接受""本版已修复"这类先验结论，最多客观列出待审素材、剧本目标、上一版问题。每次都重新看实际素材本身。

## 结论怎么给（最重要）
每次审查第一句必须是明确的**通过 / 不通过**——这是审查唯一的产出目的：决定它能不能进下一环。然后：不通过就逐条说清哪些问题导致不通过、每条配一个具体修改建议；通过就简单说看了哪些点、为什么放行。

## ⭐ 两套尺度（最关键，别用错）
审查对象不同，严的地方完全不同。用错尺度是最常见的失败——要么拿成片的严标准去抠一张参考图，把本来够用的素材反复打回、重抽、覆盖，把"其实第一版就挺好"的图弄没；要么拿参考图的松标准去放行成片，让多人物、叙事、画面文字、镜头语言这些硬伤溜进去。

### 尺度 A · 基准图/参考图 —— 放松，只看"能不能用来锁一致性"
角色三视图、道具图、场景图、风格锚图，它们**唯一的作用是给后续生成当参考、锁住人物/物体/风格的一致性**。所以判通过只问一件事：**整体基调对不对、后面能不能靠它认出这是同一个人/同一个东西/同一种风格。**

- **只要身份特征稳定、基调统一，就放行。** 角色看的是贯穿全片要保持一致的东西：脸型、五官、发型发色、肤色、身材骨架、服装款式与配色。这些对了、整体观感干净，就通过。
- **基准图不是服化道像素验收。** 角色参考图的目标是防止后续视频换脸、换衣、变形；不要把马尾高低、酒窝凹陷是否明显、手表在左手还是右手、徽章偏左偏右、眼镜反光、袖口褶皱这类小细节列成打回项。除非这些细节本身是剧情线索/品牌资产/角色身份唯一识别点，否则最多记为小瑕疵，不阻塞进入下一环。
- **不要抠参考图细枝末节**：三视图小比例末端融边、不同角度形态差异、中性表情、非标准"正侧背"排版、左右对称特征翻转，都不该单独打回。判定标准只有：身份特征是否存在、大致区域是否对、整体还认不认得出同一人/同一物。真正要拦的是核心特征消失、换成不同东西或结构错误会污染后续一致性。
- **AI 生成标识不是瑕疵。** 参考图/故事板上保留官方「AI 生成」水印或标识，默认不算质量问题，也不作为打回理由；它能帮助后续环节把素材识别为 AI 参考资产而非真实人物/真实照片。只有标识遮住了剧情必须读清的文字、关键道具或核心构图时，才作为遮挡问题处理。
- **真要拦的只有**：核心身份特征画错了（脸型/五官/服装/配色/斑纹明显不对、换了个人）、整体风格跑偏、明显且放大成立的真结构错误（手指数量明显不对、关节反折、肢体扭曲）、严重错色（要求黑瞳却异色瞳）。这些会污染后续所有画面，必须拦。
- 审之前先确认这张图原本按什么形式生成（看生成要求或资产规则），审查目标继承这个原始意图，别用别的成图标准去套。

### 尺度 B · 成片 / 视频片段 —— 从严，盯三类最容易塌的地方
视频是要交付给观众看的，这里要严，重点盯下面三类（这三类是短片质量塌方的主因）：

1. **多人物**：有多个角色同框时，重点看有没有串脸、多人同脸、角色身份漂移、A 的脸长到 B 身上。单人镜头还要警惕"镜中复刻分身/凭空多出一个人"。
2. **起承转合**：观众不看剧本只看片，能不能看懂发生了什么、为什么发生、情绪怎么递进、反转落哪。尤其盯——前三秒有没有钩子（平淡铺环境、信息滞后就是节奏问题）；镜头衔接处剧情因果断没断（转场只解决视觉衔接，不解决因果）；剧本里的关键反转/线索/动机有没有真的被观众从画面里看见并理解。审查时不要用“我知道剧本所以能解释”来替素材开脱：如果一个第一次观看者只凭画面、画面文字和可见叙事线索连不上 A 为什么到 B，就按叙事问题处理。人物情绪也按这个标准看：不是哭得多就好，而是观众能不能看出情绪被什么触发、如何从眼睛/嘴角/呼吸/手部等细节一步步流露出来。
3. **穿帮与物理规律**：画面再漂亮，只要空间、接触、重力、遮挡、道具连续性明显违背现实或本片设定，观众会立刻出戏。审查时必须主动找穿帮，不要只问"主体像不像/动作有没有发生"。

**本版本不把音频作为审查维度。** 审查 question 里不要问音频/音轨/人声/BGM/配乐/环境声/旁白/画外音/台词是否听到/口型/尾音/爆音/静音，也不要写"是否无旁白/无人声/无口型/无音频问题"这种负向确认。审查只判断画面、叙事、画面文字、角色、镜头语言、结构和物理穿帮；不要因为模型说未检测到音轨、听不清人声、没有 BGM 或口型不确定就判不通过。音频仍在剧本、编导和生成前编译阶段写好，但不交给 VLM 判通过。

**穿帮/物理规律要单独列问题审，不要埋在"画面质量"里。** 图像和视频都要看，视频更要逐段看开头、中段、结尾和动作接触瞬间：

- **空间连续性**：人物、道具、门窗、桌椅、道路、地平线、室内外关系是否前后自洽；镜头一切，主体位置/朝向/左右关系/距离突然变化，属于穿帮。
- **接触与支撑**：脚是否真正踩在地面/台阶/道具上，手是否真的握住杯子/剑/方向盘，人物坐下时身体是否被椅子支撑；悬空、滑行、穿进物体、手和道具错开但假装拿着，属于硬伤。
- **重力与受力**：跳跃、坠落、碰撞、奔跑、推拉、开门、抛物、液体飞溅是否有合理方向和反应；人物被撞却没有身体反馈、重物像纸片飘、落水没有水花、踩物体不产生承重变化，属于物理问题。
- **遮挡与层级**：前景/中景/背景遮挡关系是否正确；手臂穿过身体，衣服穿过椅背，人物从墙里长出来，道具在人物前后层级乱跳，都要点名。
- **身体结构与动作链**：手指数量、关节方向、四肢连接、头颈比例、步态、跑跳落地是否合理；持续几帧以上的肢体融化、关节反折、腿脚错位、身体滑行不能放过。
- **道具与服化道连续**：关键道具是否凭空出现/消失/变形/换手，服装颜色和发型是否在同一段内跳变，伤口/污渍/品牌标识/屏幕内容是否前后不一致；如果它承载剧情或商业信息，错了就不通过。
- **AI 生成常见穿帮**：脸部五官漂移、手部融化、边缘拉丝、主体和背景粘连、影子方向乱、倒影不对应、文字贴片跟随错误、镜中/水中反射多出人物，都要主动查。

分寸：极远背景里不影响理解的小人形、快速运动造成的轻微动感模糊、Q 版/夸张动画故意违反现实比例，不要按真实物理过度打回；但只要穿帮发生在主体、关键动作、人物表演、道具交互、转折点或商业/剧情信息上，就按质量问题处理。要求的核心动作有没有清楚完成、闪烁拉丝融化、镜头起止帧、画面内文字、链式/延长片段接缝，也仍然要查。

还要看**镜头语言**：编导方案里的景别、明确视角类型、机位、运镜、焦点景深、主光方向、变速和首尾镜咬合有没有真的拍出来。重点抓两种扁平化：单段全程一个景别/机位、没有景深或运动层次；段与段首尾镜各拍各的，没承接。空镜、单一反应、刻意固定长镜可以简单；只拦该有设计却被拍成"机位摆那拍人物做动作"的段落。还要专门看三件事：① 视角是否明确且符合 plan（第一人称/第三人称斜后方/无人机/物体内部视角等不能被拍成普通正面机位）；② 光线是否符合镜头设定和故事时间（太阳角度、窗光方向、月光/灯光来源不能乱）；③ 空间方向是否清楚（人物往哪跑、谁看向谁、从哪进房间/出门，不能前后跳方向）。

**莫名其妙的镜头要拦。** 有些镜头画面漂亮但不承担叙事功能：不知道它在交代谁、哪、什么线索、什么情绪变化、什么空间转场，或和前后镜头没有因果关系。审查时要直接问“这个镜头为什么现在出现？它让第一次观看的观众多知道了什么？”答不上来就不能因为画面好看放行；修复建议回到编导方案，补叙事动机、改成信息镜头，或删掉。

**情绪表演要审因果和过程。** 情绪镜头不能只看“有没有哭/笑/愤怒”，要看触发点、压抑或转折、外部流露是否成立：上一秒什么信息击中了人物？表情是先僵住、躲开视线、眼睑变重、嘴角抿紧、呼吸断掉，还是直接跳到大哭？如果情绪结果很强但没有触发原因、没有逐步变化、脸部和身体细节对不上，就按表演/叙事问题处理。

**质感要按四层审，不只看清不清。** 图像和视频都要判断真实感来自哪里：① 环境层有没有空气悬浮物、雾/烟/尘/雨丝、湿度、体积光、空气透视和远近层次；② 镜头层有没有合理的感光颗粒、景深、焦点、镜头眩光、bloom/halation、运动模糊或前景遮挡；③ 材质层的皮肤、布料、金属、木石、玻璃、水、纸张等有没有真实反射/吸光/透光、粗糙度、磨损、油光、接触面和尺度；④ 显影层的色彩、阴影密度、明暗对比、饱和度、黑位和高光是否统一。不是每层都必须重，但如果画面只剩“高清锐利”而没有空气、光学、材质和色彩显影逻辑，就不能算真正有质感。

> 本版本不审"是否缺台词字幕/CTA"，但画面内文字必须审。编导设计并画进画面的片名/剧名卡、人名牌、章节标题、时间卡、地点卡等，逐处核三件事：内容逐字正确清晰、没有乱码/截断/冲出画面；出现/消散时机和动效按 plan 执行；样式与全片统一。承担叙事的时空/身份标识缺失或读不清，按问题处理；文字乱码/错字属硬伤。

**还要审"该有文字路标却没有"。** 3 个及以上 segment 的复杂叙事内容，至少一半 segment（向上取整）应有时间卡、地点卡、章节卡、人名牌/身份牌、关键概念短卡、片名/主题短句等文字路标；只在片尾落版不算足够。低于覆盖率，或多个无文字 segment 没写不上字理由，直接判**不通过**，修复建议回编导方案补文字路标。

审查 question 要明确问：全片是否有足够的文字路标帮助第一次观看的观众认清时间、地点、人物身份、章节跳转和关键概念；哪些 segment 缺少文字导致前因后果看不清；已有文字是否清晰可读并按计划出现/消散。这个检查只看画面和画面内文字。

## 通用维度（两套尺度都围绕这些看）
一致性（同一对象在不同画面是否同一个样）、风格统一（最严的是同片混进完全不同画风，如写实和动画混搭）、物理常识、内容忠实（有没有答非所问）、画面质量（清晰度/构图/噪点/瑕疵）。

## 六个审查场景
1. **审基准图**：用尺度 A。
2. **审单个画面**：看这张自身有没有硬伤、内容对不对得上对应片段要求。是逐张看自己那张。单图同样要查穿帮：主体是否穿模/悬空/手指崩坏/道具握不住/遮挡层级错/镜面倒影不对；参考图按尺度 A 放松，但明显会污染后续一致性的结构错误仍要拦。
3. **审故事板/分镜图**：故事板是故事流动、构图与节拍蓝图，不是普通参考图。先看是否继承本段角色/场景/道具参考，再看是否有多宫格、多面板、镜头顺序、主体位置变化、动作/情绪/信息递进、箭头/标号。复杂动态、强反转、多关键信息段如果只是一张精修氛围图或概念场景图，判不通过。手绘线稿、潦草、弱色彩不是缺点；要拦的是单帧写实成片图、静态设定图、没有顺序推进的漂亮图。
   - **故事板硬性打回项（出现任一条直接判不通过，别放行）**：① 整张就是一张单帧画面、看不到多个分格（panel）；② 画成了电影级写实/photorealistic/cinematic 精细上色的成片质感，而不是手绘线稿草图；③ 格与格之间没有任何箭头/标号/顺序线，看不出镜头先后和运动方向。这三条是反复发生的真实事故（agent 把每段画成一张漂亮写实单帧、还自称 storyboard），是审查这一关存在的首要意义。审查 question 必须分别点名问清："这张图是单帧还是多宫格？""是手绘线稿草图还是写实成片画风？""格间有没有顺序箭头？"——三个都答对才放行，含糊带过不算。
4. **审段间衔接（每段单独审过之后必做，别只审段内）**：逐段视频各自审完≠拼起来就顺。把相邻两段接在一起看这个"接缝"本身——上一段结尾和下一段开头之间，画面有没有跳脱（主体位置/景别突变、风格色调断层、明显硬切看着出戏）、运镜有没有按编导设计咬合（首尾镜该承接的有没有承接）、动作/视线/焦点的承接是否成立、计划中的叠化/黑场/淡出淡入是否真正形成换气或章节感、链式延展段有没有跳变回退重复帧。判定就看一件事：观众从上一段进到下一段，是被自然带过去，还是"咯噔"一下出戏。出戏就点名是哪个接缝、什么问题、该用哪种转场（镜头承接/渐变/留白/淡出淡入/黑场）补。
5. **审画面整体**（关键，最容易被偷懒跳过）：把所有片段的关键画面放一起，横向比风格、色调、光影、造型是否统一。这一步和逐张审是两回事——逐张全过不代表放一起不跑偏。不能因为逐张审过就跳过。故事板整体审查还要额外横向看：各段是否都按复杂度选择了合适的分格数量和节拍表达，是否有某几张退化成和资产参考图没有区别的单帧漂亮图。
6. **审成片**：用尺度 B，站在"完整一部片"的高度终审。警惕陷阱：逐段审每段都"还行"，拼成整片后跨段的风格割裂、角色前后不一、叙事断裂才暴露。

## 成片终审怎么审得扎实
别笼统顺一遍，要定点检查：

- 对照 `script.md`、拍摄表、成片，核对核心信息是否真进了成片。
- 查前三秒钩子；每个镜头衔接处前后停一下看突变。
- 抽看开头、结尾和中段，确认风格一致、叙事连贯、角色长相稳定。
- 核对承担叙事的画面内文字、文字路标覆盖率和因果链。
- 按不看剧本的第一次观看者复盘每个 segment：主角是谁、在哪里、为什么从上一段来到这里、这一段新增了什么信息、下一段为什么成立；出现解释不了的漂亮镜头就标记为莫名镜头。
- 对照 `director_plan` 抽查逐镜视角、光线和空间方向：视角类型有没有拍准，太阳/月光/窗光/灯笼/屏幕光是否符合故事时间和方位，人物朝向、视线、进出房间和运动方向是否前后自洽。
- 抽查关键情绪镜头：情绪是否有可见触发原因，是否通过眼睛、嘴角、呼吸、手指、肩背等细节推进，而不是突然切到一个结果表情。
- 抽查画面质感四层：环境空气、镜头光学、材质反射/触感、显影色彩与阴影是否共同成立，是否存在过度磨皮、塑料质感、背景贴片、光学效果乱用或色彩阴影跳变。
- 逐段抽查穿帮和物理规律，尤其看接触点、跑跳落地、道具交互、遮挡层级、镜头接缝和主体漂移融化。
- 检查交付适配（平台画幅、节奏；本版不含后期对白字幕）。

终审同样不做音频审查，不让"听不出人声/BGM/环境声"成为不通过理由。

再做一次**盲看故事复述**：不把剧本、导演意图或片段计划喂给审查者，只让它看成片后回答：主角是谁、她想解决什么、关键阻碍是什么、发生了什么转折、结尾解决了什么、哪些地方突然跳走或没看懂。这个环节专门抓"逐段看都还行，整片却不知道在讲什么"的问题。盲看复述不出主线，或只能列出一串无因果的画面，成片就不能通过。

### 成片终审硬性打回项（出现任一条，除非用户明确接受，判不通过）
- 前三秒没有明确钩子。
- 核心画面内文字乱码/错字/看不清，或与剧本关键句不一致。
- 复杂叙事项目的文字路标覆盖率不足：少于一半 segment 有时间/地点/身份/章节/关键概念等文字支架，或无文字 segment 没有合理不上字理由，导致第一次观看者难以理解前因后果。
- 剧本关键反转/核心线索/人物动机没在成片画面中被看见或理解。
- 镜头只是视觉接上了但剧情因果断裂，观众无法理解为什么从 A 跳到 B。
- 出现无叙事功能的莫名镜头：画面好看但不交代人物、地点、线索、情绪变化、空间转场或因果关系，导致第一次观看者不知道它为什么出现。
- 关键情绪镜头只有结果没有过程：比如突然大哭/突然愤怒/突然释然，但看不出触发原因，也没有眼神、嘴角、呼吸、手部或身体细节的渐变。
- 关键镜头质感塌陷：只有锐化和“高清”，缺少环境空气、镜头光学、材质反射/触感或显影色彩阴影逻辑；写实真人出现明显磨皮、塑料皮肤、零毛孔蜡像感。
- 编导方案明确要求的视角、光线或空间方向被拍丢：例如第一人称/无人机/物体内部视角变成普通机位，太阳光方向和时间明显冲突，人物朝向/视线/进出房间方向前后不自洽并影响理解。
- 盲看复述说不出主角目标、阻碍、转折和结尾 payoff，或把关键因果理解错。
- 多人物场景出现串脸/多人同脸/角色身份漂移；单人镜头凭空出现同款分身、双胞胎或把多视角参考误生成多人。
- 主体或关键动作出现明显穿帮：人物/道具穿模、悬空、脚不落地、手没握住道具、重力/受力方向明显错误、关键道具凭空出现消失、主体持续融化变形、遮挡层级严重错误。
- 链式/延长片段衔接处出现明显画面跳变、动作回退、重复帧或主体位置突变。
- 终审问题里预设"已通过/已接受/已修复"诱导放行。
- 只修了局部（裁短/加转场/调色），但上一版的叙事断层、情绪铺垫不足、反转无力没从结构上解决。

## 不合格之后怎么办（闭环）
审查不是打个分就结束：发现问题→整理修复计划→判断源头在哪一环（基准图错了？画面跑偏？只是这段视频的问题？）→选能真正解决的修法→重做后再审一遍。

- **重做要带针对性修改意见去改，不是原样重抽碰运气。** 个别局部瑕疵就把上一版当参考喂回生成环节、只改点名那处；整体跑偏才换思路重做。
- **每次重做另存新版本，绝不覆盖原文件**——常常较早某版反而最好，留着才能回头挑。
- 设**重做上限**：同一问题反复几轮过不了，就如实记录残留问题交用户判断，别无限循环卡死。
- 修复计划要逐条闭环（问题是什么/影响哪一环/是否阻塞交付/怎么修/为什么这个修法能解决/修完证据）。不要把所有问题都用同一种修法（转场只解决视觉衔接，不解决因果/角色漂移/画面文字错误）。复审必须逐条对照修复计划核验，不是笼统问"现在通过吗"。

## 不可省略的硬规则
- 任何一张图、任何一段视频，交付或进入下一环前都必须经过审查。
- 画面整体审查（放一起横向比）必须做，不能因为逐张审过就跳过。
- 成片终审必须站在完整整片高度做，不能用逐段审结论替代。
- 审出的硬伤必须进修复计划、真的回去重做并复审，不能只记录却照样放行。
