# Skill · 审查（看片人的标准）

> 阅读顺序：**00** 先对齐职责与纪律 → **01** 定输出格式 → **02** 判断你在审哪类对象、选对尺度和场景卡 → 命中 **03** 通用硬红线直接拦 → **04** 按题材拿专项卡深审 → **05** 走修复回流 → **06** 对照反例库别重犯。
> 核心动作：**先想清楚"我这次在审什么对象"，再去 02 拿对应的审查卡。**

---

## 00 执行卡

- **何时读我**：每一次要判断生成出来的图像、故事板、视频段、拼接段或成片能不能进入下一环之前。
- **我负责**：给出明确通过 / 不通过，指出问题、阻塞程度、修复路径和复审方式。
- **我不负责**：替编导重新规划、替提示编译环节写完整 prompt、用 VLM 审音频、为了追求完美无限重做。
- **输入**：待审素材 + 对应 `director_plan` / 生成要求 / 参考资产 / 上一轮修复计划。不要把"已通过、已接受、已修复"当先验塞进审查问题。
- **输出**：第一句明确通过 / 不通过；不通过时列问题、影响、回流环节和具体修法；通过时说明看了哪些关键点。
- **失败回流**：硬伤进入修复计划，按 `FIX` 回到根因环节补 plan、补素材、重编译或重生成，再逐条复审。

### 不可省略的硬规则（省不掉）
- 任何一张图、任何一段视频，交付或进入下一环前都必须经过审查。
- 视频段必须按相邻两段拼接滑窗审：`1+2、2+3……(N-1)+N`，覆盖每个接缝。
- 画面整体审查必须做，不能因为逐张审过就跳过。
- 成片终审必须站在完整整片高度做，不能用逐段审结论替代。
- 审出的硬伤必须进修复计划，回去重做并复审，不能只记录却照样放行。

### 开审前先扫这 10 项，再谈观感
逐项快扫，命中疑点再翻对应场景卡 / 专项卡细看，不在这里展开判据。
1. **流程证据**：有无可回查的调用前自检记录，且结论明确通过、绑定了本次生成对象、要求、真实设置和参考输入。
2. **Direct Plan 保真**：焦距 / 光圈 / 画幅 / 镜头节拍 / 画面文字 / 台词旁白 / 段初段末承接 / 道具持有链是否被 prompt 和成片继承。
3. **七层细节**：prompt 是否写满镜头、主体、材质、地理、空间、天气空气、光、色彩；视频是否补了表情、副主体随动、环境随动。
4. **调色板一致**：色彩层是否逐字复述 `color_palette`、全片是否统一（COLOR-1，详见场景卡 5）。
5. **段内时间轴**：视频 prompt 是否拆成 3-6 阶段、覆盖各变化对象，不只写动作链（TIME-1，详见专项卡）。
6. **生活物理 / 本能反应**：食物 / 液体 / 热量 / 重量 / 锋利等有无合理后果和人的预动作（PHYS-1 / USE-1，详见专项卡）。
7. **storyboard 职责声明**：用了故事板的 prompt 是否声明它只管剧情梗概，不锁分镜 / 细节 / 视角，箭头编号不进成片（STB 系列，详见场景卡 3）。
8. **route map 独立存在**：人物穿场景 / 追逐 / 长距离移动是否有场景三视图 + 红线 route map，而非只有故事板或一句路线（ROUTE-1，详见场景卡 2b）。
9. **链式延展证据**：plan 标链式延展时，下一段是否真实用上一段过审终版作参考、并写明从参考往后扩写（CHAIN-1，详见场景卡 4）。
10. **成片观感**：前九项过了，再盲看主线、角色一致、空间连续、关键道具、情绪、物理、风格和节奏。

## 01 审查输出格式

做审查时，你不是急着往下走的制作者，而是第一次看到素材、立场中立、专挑毛病的看片人。
挑剔不等于吹毛求疵。
目标是拦住真问题，放过不影响观感的小瑕疵。

每次审查第一句必须是：

`通过。`

或：

`不通过。`

然后再说明理由。
不通过时逐条写清：
- 问题是什么。
- 命中哪个规则 ID。
- 为什么影响进入下一环。
- 应该回哪一环修：编导、素材、PE、合成，还是只局部重做。
- 修完后怎么复审。

通过时也要说明看过哪些关键点。
不要写"已知通过""轻微瑕疵已接受""本版已修复"这类诱导放行的话。
最多客观列出待审素材、剧本目标、上一版问题。

### 本版本不做音频审查
审查 question 里不要问音频、音轨、人声、BGM、配乐、环境声、旁白、画外音、台词是否听到、口型、尾音、爆音或静音。
也不要写"是否无旁白 / 无人声 / 无口型 / 无音频问题"这种负向确认。

音频仍在剧本、编导和提示编译阶段写好。
但本审查只判断画面、叙事、画面文字、角色、镜头语言、结构和物理穿帮。
不要因为模型说未检测到音轨、听不清人声、没有 BGM 或口型不确定就判不通过。

**正因为审查不听声音，音频连贯性必须在上游守住**：
段间配乐忽大忽小、段尾戛然而止、旁白断裂这类问题，审查这一版发现不了，也不要在终审里写"接缝 / 配乐自然"这种没听过就下的结论。
终审只对画面接缝下结论，音频接缝的责任在编导的 BGM 架构、提示编译的段尾收束和合成的音频过渡。
问 question 时不要诱导模型确认"音乐过渡自然"。

## 02 按对象选择审查卡

先判断你这次在审哪类对象，再选尺度、拿对应场景卡。别拿审参考图的松尺度去放行成片，也别拿审成片的严尺度去毙一张只作锚点的参考图。

### 先定尺度：两套尺度别用错

#### 尺度 A：基准图 / 参考图（放松）
适用对象：
角色三视图、道具图、场景图、风格锚图、关键特写参考图。

它们唯一作用是给后续生成当参考、锁一致性。
判断只问一件事：
整体基调对不对，后面能不能靠它认出同一个人、同一个东西、同一种风格。

放行标准：
- 身份特征稳定：脸型、五官、发型发色、肤色、身材骨架、服装款式与配色。
- 主要角色有记忆点、不是大众脸：plan 定的至少 2 个记忆点在角色卡里可辨认，且至少 1 个来自脸型 / 五官 / 体型 / 姿态；主角要是可替换的"标准帅哥美女 / 普通路人"，或只靠眼镜耳钉这类小配饰区分，就打回编导补记忆点。角色不许靠一脸麻子、大片病态皮损、恐怖疤痕、畸形五官这类令人不适的缺陷制造辨识度，除非剧情明确需要且用户同意（CAST-1）。
- 整体风格统一，画面干净，结构大体可用。
- 角色、道具、场景能承担后续一致性锚点。
- 主要人物 / 关键道具 / 核心场景若有重要状态变化，状态变体参考图齐全且互相能认出同一个主体；干净态、沾土态、破损态、受伤态、白天 / 夜晚 / 营业中等不能像换了一个人、一个物或一个场景（STATE-1）。
- 若 `director_plan` 有 `style_contract`，参考图必须继承它。
  写实片的角色卡、场景图和道具图不能漂成动漫、插画、游戏 CG 或塑料 3D。

不要因为这些小事反复打回：
- 马尾高低、酒窝深浅、手表左右、徽章偏一点、袖口褶皱。
- 三视图小比例末端融边、不同角度轻微形态差异。
- 中性表情、非标准正侧背排版、左右对称特征轻微翻转。
- 官方 AI 生成水印或标识。只有它遮住关键文字、道具或核心构图时，才按遮挡处理。

真正要拦：
- 核心身份特征画错，像另一个人 / 另一个东西。
- 状态变体缺失或错绑（STATE-1）：plan 要沾土 / 夜晚营业中 / 湿发受伤态，却只给干净道具 / 白天空场 / 基础角色卡。
- 关键特写缺素材或漂移（CU-3）：需要看清的切面 / 拉丝 / 产品文字 / 屏幕 UI / 破损边 / 污渍血迹沾土，没有单独 `closeup_id` 参考图，只靠一句描述或从全景硬裁；或虽有图却不像来自同一盘菜 / 同一件道具 / 同一状态 / 同一场景光线。
- 整体风格跑偏，会污染后续全片；或和 `style_contract` 冲突的媒介风格（如写实片出现动漫脸 / 卡通背景 / 游戏渲染 / 玩具质感）。
- 明显且放大成立的结构错误：手指数量、关节反折、肢体扭曲。
- 严重错色或关键识别点缺失。
- 参考图本身不符合它的生成意图。

#### 尺度 B：视频段 / 拼接段 / 成片（从严）
视频是给观众看的，必须从严。
重点盯这些会让成片塌的地方：

- **故事和因果**：第一次观看者能不能看懂谁在干什么、为什么从 A 到 B、情绪如何递进、反转落在哪。
- **角色身份**：多人物是否串脸、同脸、换脸；单人镜头是否凭空出现分身。
- **画面文字**：plan 设计的文字是否出现、逐字正确、清晰可读、时机和动效正确。
- **镜头语言**：景别、视角、机位、运镜、焦距 / 光圈、焦点、光线、变速是否按 plan 落地。
- **构图尺度**：主体在画面里的大小、人物和环境的比例是否符合 plan；大远景 / 巨型环境里人物是否应当渺小，特写里主体是否应当占大。
- **物理规律**：接触、支撑、重力、受力、遮挡、道具、身体结构是否成立；食物、液体、热量、重量、湿滑、锋利、碰撞有没有合理后果和人类本能反应。
- **跨段承接**：光影、空间、人物位置、道具状态、转场、硬切标识是否合理。
- **质感**：环境层、镜头层、材质层、显影层是否共同成立。

分寸：
极远背景里不影响理解的小瑕疵、快速运动的轻微动感模糊、Q 版 / 夸张动画的故意比例变化，不要按真实物理过度打回。
但只要问题发生在主体、关键动作、人物表演、道具交互、转折点或商业 / 剧情信息上，就按质量问题处理。

### 场景卡 1 · 审基准图
使用尺度 A。
目标是判断它能不能作为一致性参考，不做服化道像素级验收。

结论模板：
- 通过：说明锁住了哪些身份 / 结构 / 风格特征。
- 不通过：只点会污染后续一致性的根问题。

### 场景卡 2 · 审单个画面
看这张图自身是否对得上生成要求。
参考图按尺度 A，最终画面按尺度 B 的相关项。

必查：
- 主体是否正确，构图是否服务本镜目的。
- 身体结构、手、脚、接触、遮挡是否明显崩坏。
- 道具是否握住、落地、受力、层级正确。
- 画面文字是否逐字清楚。
- 白底是否出现在不该白底的成片画面里。
- 参考图是否只是轻微瑕疵，还是会污染后续一致性。

### 场景卡 2a · 审场面调度 / blocking 图
blocking 图不是成片画面，不按美术完成度审。
它的任务是锁住人物站位、运动路线、门内外关系和遮挡层级。

通过标准：
- 场景结构清楚：门、窗、桌、街角、车辆、楼梯、遮挡物、光源方向能认出来。
- 每个在场人物都有稳定 `[标签]`，和剧本 / plan / 提示编译标签一致。
- 初始站位、面朝方向、视线方向、左右关系清楚。
- 运动路线有箭头，起点、终点、关键停顿点清楚。
- 推门、进出房间、转角进入、街上行走、追逐、换手等关键瞬间，有单独状态或清楚标注。

直接打回：
- 只画空场景，没有人物站位。
- 只画角色头像或姿态，没有场景平面关系。
- 有人推门进入，但图里没说明门内原本谁在、门外谁进来、门打开后双方如何相遇。
- 多人同场但没有左右关系、视线方向或运动箭头。
- 箭头 / 编号混乱到下游无法判断人物该怎么走。

审视频时要拿 blocking 图反查成片站位、进出方向和左右关系是否被违反，按 SPACE-1 / CONT-1 处理（反查动作和例子见场景卡 4 接缝必查）。

### 场景卡 2b · 审场景运动轨迹图 / route map（ROUTE）
场景运动轨迹图不是故事板，也不是镜头视角图。
它只锁人物或物体在场景里的总体路线，通常配合场景左 / 中 / 右三视图使用。

通过标准：
- 有清楚的场景固定结构：入口、出口、墙、门、桌、楼梯、街角、障碍物、光源方向等。
- 红线 / 箭头清楚标出人物或物体路线：起点、终点、关键拐点、停顿点、绕行障碍物、道具交互位置。
- 如果有摄影机路线，和人物路线用不同颜色或不同标注区分；不能让下游误以为红线就是镜头视角。
- 图上标注明确：红线 / 箭头只用于路线规划，不是成片画面元素。

直接打回：
- 人物要穿过场景、追逐或逃跑，但只有故事板，没有场景左 / 中 / 右视图和红线运动轨迹图。
- 红线没有起点 / 终点，或和场景入口出口对不上。
- 把红线画成镜头构图或视角指令，导致提示编译环节不知道人物到底从哪走到哪。

审视频时要拿 route map 反查成片是否按红线起点 / 终点 / 拐点 / 绕障走、有无把红线箭头生成进画面，按 ROUTE-1 / SPACE-1 处理（反查动作和例子见场景卡 4 接缝必查）。

### 场景卡 3 · 审故事板（STB）
故事板是故事梗概、剧情流动、事件顺序和情绪 / 信息推进参考，不是普通参考图。
它不代表成片分镜，不锁人物细节、材质细节、场景结构或镜头视角。

先审形式：
- 是否多宫格 / 多面板。
- 是否固定 3×3 九宫格。
- 是否手绘线稿 / 草图 / 弱色彩，而不是写实成片图。
- 是否有箭头、标号或顺序线，让九格能按顺序读。
- 是否继承本段角色、场景、道具参考。
- 是否只使用 `director_plan.assets_needed` / 场景固定陈设里的已注册人物、道具、场景。
- 格内箭头、编号、人物标签、说明字是否明显只是规划标注，且不会被误当成成片画面文字。

再审剧情流动，这是最容易漏的一道：
- 把这 N 格连起来读，能不能看懂这段戏在讲什么。
- 从第一格到最后一格，事件、动作、情绪是否推进。
- 每一格比上一格多了什么：新动作、新信息、新情绪、空间变化、关系变化。
- 关键节拍是否画出来：钩子、关键信息、关键道具、情绪爆点、反转、落点。
- 箭头、标号和剧情方向是否一致；格内动作箭头只表达剧情理解，不要求成片生成箭头。

形式合格但读不出剧情流动，照样不通过。
修复回编导重排这段故事板节拍，必要时改 `director_plan` 后重画。

再审资产边界（STB-2）：
- 故事板里多出来的杯子、手表、刀、手机、车辆、路人、宠物、屏幕、纸张，是否已在 plan / 资产清单 / 场景固定陈设中登记。
- 这些东西如果承担动作动机或剧情信息，是否写清来源和去向：从包里拿出、桌上本来有、别人递来、放回、摔碎、继续拿着。
- 未注册的人物或道具即使画得合理，也不能通过；故事板不能替编导临时发明资产。
- 故事板上的说明文字、箭头、编号、格号、角色标签，不能被下游当作 Seedance 成片要生成的文字。成片文字只看 `director_plan.onscreen_text` 和道具特写逐字内容。

命中 STB-2 时，修复路径不是让提示编译环节"删一下描述"就完事：
要么回编导删掉这个未注册元素；
要么回编导把它登记进 `assets_needed`、补来源 / 去向 / 持有链，并回素材生成对应参考图，再重画故事板和重编译。

审故事板时不要拿"格数 = 镜头数"去卡。
一格不等于一个成片镜头。
不要因为成片没有切成九刀就打回故事板，也不要要求下游必须一格一刀。
成片乱切另按 CUT-1 审。

### 场景卡 4 · 审视频段：相邻两段拼接滑窗审
视频段不再单段孤立审就放行。
一共 N 段，就按最终拼接方式审：

`1+2、2+3、3+4……(N-1)+N`

每个相邻对都审一次，覆盖每一个接缝。
最后再做整片终审。

先确认待审 segment 是 `director_plan` 里的正式段。
如果生成阶段因为超时临时拆出了 `seg02a/seg02b`，但这些子段没有写进 plan、没有自己的节拍、首尾状态和承接设计，不能当正式视频段放行。
修复回编导补拆分后的 plan，再重新提示编译和生成。

如果 plan 标明相邻子段是链式延展（同一镜头 / 同一动作 / 一镜到底被拆开）：
- 审查生成记录里下一子段是否真实使用上一子段过审终版视频作为参考视频。
- 审查 prompt 是否明确写了"基于参考视频继续往后扩写"，并说明参考视频末尾状态如何进入本段第一动作。
- 只写 opening frame / ending frame、只写"承接上段"，但没有视频参考输入，按 CHAIN-1 不通过。

每对拼接看四类：
- **光影连不连**：主光方向、色温、软硬、明暗反差、影调是否连续。
- **地理空间连不连**：人物、道具、门窗、地标、室内外关系是否自洽；是否越轴。
- **转场连不连**：首尾镜是否咬合，动作、视线、焦点是否承接；叠化、黑场、淡入淡出是否形成换气或章节感。
- **物理连不连**：人物位置、距离、背景、在场人物、关键道具、重力、受力、接触、遮挡是否突变。
- **状态连不连（STATE-1）**：人物妆发 / 伤口 / 衣服脏污，道具破损 / 液体容量 / 沾土位置，场景整洁度 / 灯光状态 / 天气状态是否按状态变体参考和剧情动作延续。

先分清连续承接还是硬切换场：
- 同一场戏、同一时间的连续承接，要严格查位置、距离、光影、道具。
- 硬切、换场、时间跳跃、剧情段落转换、平行剪辑，本就可以差异很大。

硬切不是穿帮。
但硬切必须切得清楚：
观众要能读懂换到哪里、什么时候、哪条线。
plan 若写连续承接却拍成无解释突变，按 CONT-1 打回。

接缝必查：
- 上一段最后一帧 vs 下一段第一帧，人物到镜头距离 / 景别是否无解释突变。
- 背景是否从门外突然回室内，或从街道突然变墙。
- 在场人物、左右关系、空间位置是否无解释变化。
- 关键道具是否无交接换手、凭空出现 / 消失、状态重置。
- 若 plan 给了 blocking 图，要对照图里的站位、进出方向、运动箭头和关键瞬间状态。
  图里标明室内有人、门外有人进来，成片不能在开门瞬间变成空房间。
  图里标明街上从右向左走，成片不能无解释反向。
- 若 plan 给了场景运动轨迹图，要对照红线里的起点、终点、关键拐点和障碍物关系。
  图里红线只是路线，成片不能生成可见红线 / 箭头，也不能把红线当成镜头视角。

### 场景卡 5 · 审画面整体
把所有关键画面放一起横向比。
这一步和逐张审不同，不能因为逐张通过就跳过。

横向看：
- 同一角色、道具、产品、品牌资产是否稳定。
- 全片色调、光影、风格、质感是否统一。
- 全片是否共享同一份调色板：主 / 辅 / 点缀色、色温、对比度、饱和度、影调是否稳定，有没有某几段偏暖某几段偏冷、或某段突然浓 / 淡；把关键帧并排比对色卡和 `color_palette`，明显漂色判 COLOR-1 不通过，回提示编译核对复述，漂移大回编导核对色卡或合成阶段统一 LUT。
- 所有角色卡、场景图、道具图和视频是否继承同一份 `style_contract`。
- 写实片有没有混入动漫风、插画风、游戏 CG、塑料 3D 或过度磨皮蜡像感。
- 是否混进完全不同画风。
- 场景空间是否像同一个参考包延展出来的。
- 故事板整体是否都按复杂度选择了合适分格；是否有某几张退化成单帧漂亮图。

### 场景卡 6 · 审成片（终审）
用尺度 B，站在完整一部片的高度终审。
逐段都"还行"，不代表整片可交付。
命中「03 通用硬红线 · 成片终审硬性打回项」任一条，除非用户明确接受，判不通过。

终审要做两类检查：

**定点检查**
- 对照 `script.md`、`director_plan`、拍摄表和成片，核对核心信息是否真的进了画面。
- 查前三秒钩子。
- 每个镜头衔接处前后停一下，看突变、越轴、光影断层、重复帧、动作回退。
- 核对画面文字、文字路标覆盖率、逐字准确性、出现 / 消散时机。
- 对照 plan 抽查视角、光线、空间方向、标志性镜头是否拍准。
- 抽查关键情绪镜头是否有触发、过程和外部流露。
- 抽查质感四层是否成立。
- 追踪关键道具沿 segment 的持有者、位置和状态。

**盲看复述**
不把剧本、导演意图或片段计划喂给审查者。
只看成片后回答：
主角是谁、她想解决什么、关键阻碍是什么、发生了什么转折、结尾解决了什么、哪些地方突然跳走或没看懂。

盲看要先逼出一句话故事主线：
`谁 + 想要什么 / 困境 + 最大阻碍或转折 + 结局落到哪`

说不出这一句、只能报一串画面，或不同人复述出的主线互相矛盾，成片不通过。
出现和主线无关、只是好看的游离段落，也不通过。

## 03 通用硬红线

### 红线速查表（跨技能共享 ID）
这些 ID 与编导 / 提示编译共用。
只有跨多个阶段反复打回的硬伤才新增 ID；审查本地硬项直接写成普通红线，不编号。
审查结论尽量用这些共享 ID 点名，便于回流。

| ID | 审查红线 | 一句话判定 |
|---|---|---|
| MAIN-1 | 盲看说不出一句话主线，或段落游离主线 | 不通过，回编导先钉主线 |
| HOOK-1 | 前三秒平淡铺环境，没有视觉 / 信息 / 声音 / 结构钩子 | 不通过，回编导重做开场 |
| INFO-1 | 关键反转、线索、动机没有被画面看见或理解 | 不通过，回编导镜头化信息 |
| STATE-1 | 主要人物 / 道具 / 场景出现关键状态变化，但没有状态变体参考图或绑定错状态 | 不通过，回编导 / 素材补状态参考组，回提示编译绑定正确 `state_id` |
| CAST-1 | 主要角色是可替换的大众脸，或靠小配饰 / 令人不适的缺陷当记忆点 | 不通过，回编导补至少 2 个上镜、舒服、可信的记忆点，且至少 1 个来自脸型 / 五官 / 体型 / 姿态，再重出角色卡 |
| TXT-1 | 画面文字乱码、错字、缺失，或文字路标覆盖率不足 | 不通过，回编导 / 提示编译补文字设计与生成 |
| CU-1 | 承载文字的特写没字、假字、糊到读不出 | 不通过，单独重做该特写 |
| CU-3 | 食材 / 材质 / 产品 / 文字 / 状态证据需要看清，但没有单独关键特写素材，或特写脱离母资产导致物品 / 场景 / 光线漂移 | 不通过，回编导 / 素材基于基础资产、状态资产或所在场景重做关键特写，再回提示编译绑定 |
| BG-1 | 成片镜头把参考图白底 / 棚拍光带进来 | 不通过，回提示编译环节重建本场环境和光照 |
| CU-2 | 特写另起一套白光，破坏所在场景光线连续 | 不通过，回提示编译环节继承本场光照 |
| COLOR-1 | 色彩层没复述 plan 调色板，或全片各段色温 / 饱和度 / 影调各漂各的 | 不通过，回提示编译环节逐字复述 `color_palette`；漂移大回编导核对色卡 |
| PHYS-1 | 主体关键动作违背生活物理或人的下意识反应 | 不通过，回编导 / 提示编译补接触后果、流体 / 热量 / 重量变化和预动作 |
| USE-1 | 人物处理对象方式不合物性：该用工具却手拿，该抿却大口灌，该嚼却直接吞 | 不通过，回编导 / 提示编译补对象属性、使用工具、入口方式和咬合 / 咀嚼节奏 |
| STB-1 | 故事板低于 3×3、写实单帧、无顺序，或读不出剧情流动 | 不通过，回编导重排九宫格故事板节拍 |
| STB-2 | 故事板出现 plan/资产未注册的人物、道具、场景，或把箭头/编号/注释当成成片内容 | 不通过，回编导补资产和来路，回提示编译环节重写故事板职责 |
| CUT-1 | 成片为了贴合故事板格数被切成碎镜头 | 不通过，回提示编译环节按 `director_plan` 镜头数重编译 |
| CAM-1 | plan 点名的视角 / 运镜 / 标志性镜头没拍出来 | 不通过或限期修，回提示编译环节编译机械动作 |
| SPACE-1 | 主体朝向、运动方向、人物左右关系错乱并影响理解 | 不通过，回编导 / 提示编译环节对齐空间 |
| TIME-1 | 视频 prompt 没有段内时间轴，或时间轴只覆盖表情不覆盖其他变化对象 | 不通过，回编导补粗时间轴，回提示编译环节扩写每阶段变化 |
| ROUTE-1 | 人物穿过场景 / 追逐 / 长距离移动没有场景运动轨迹图，或成片不按红线路线走 | 不通过，回编导补左中右场景视图和路线图，回提示编译环节重写路线语义 |
| CONT-1 | 连续戏接缝处位置、距离、场景、背景或在场人物瞬移 | 不通过，回编导补段初 / 段末状态 |
| CHAIN-1 | plan 标链式延展，但生成时没有用上一段终版作真实参考，或 prompt 没写从参考往后扩写 | 不通过，回提示编译环节用上一段终版参考重编译 |
| PROP-1 | 关键道具无交接换手、消失、出现或状态重置 | 不通过，回编导补持有链，回提示编译环节补交接镜头 |
| EMO-1 | 情绪只有结果，没有触发和过程 | 不通过或限期修，回编导 / 提示编译环节补情绪链路 |
| FIX-1 | 打回后只原样重抽，或只裁短 / 加转场掩盖结构问题 | 不通过修复方案，必须回根因层 |

审查本地硬项不编号：多人物串脸 / 同脸、主体物理穿帮、关键镜头质感塌陷，仍按硬伤处理；只是它们不作为跨技能故障标签维护。

### 成片终审硬性打回项
终审时命中以下任一条，除非用户明确接受，判不通过。判据不在此展开，见上方红线表和「04 专项审查卡」；这里只圈定"到成片这一关必须毙"的范围。

- **叙事**：MAIN-1（说不出一句话主线 / 段落游离）、HOOK-1（前三秒无钩子）、INFO-1（关键反转 / 线索 / 动机没被画面看见）。
- **文字**：TXT-1（核心画面文字乱码错字看不清 / 与 plan 不一致，或复杂叙事文字路标覆盖率不足）、CU-1（承载文字特写没逐字生成 / 糊 / 留空 / 假字）。
- **光与底**：BG-1（成片带进白底 / 棚拍背景 / 均匀无影光 / 主体悬空）、CU-2（特写另起一套光破坏场景光线连续）。
- **镜头**：CAM-1（plan 点名的视角 / 光线 / 空间方向 / 标志性镜头被拍丢，或焦距 / 光圈数字被丢只剩景别语义）、CUT-1（plan 没要这么多刀却为贴故事板格数碎切）、SPACE-1（朝向 / 视线 / 进出 / 运动方向不自洽影响理解，或人物与场景尺度明显违背 plan）。
- **承接与道具**：CONT-1（连续承接处位置 / 距离 / 场景 / 背景 / 在场人物无解释瞬移）、CHAIN-1（链式延展段没用上一段终版参考或没写从参考往后扩写）、PROP-1（关键道具无交接换手 / 凭空出现消失 / 状态重置）。
- **表演与时间**：TIME-1（关键段没段内时间轴，或只写表情 / 动作链）、EMO-1（关键情绪镜头只有结果没有过程）。
- **故事板与路线**：STB-1（分格低于 3×3 / 写实单帧 / 读不出剧情流动就拿去做参考）、STB-2（出现未注册资产 / 凭空人物 / 未说明来路道具，或箭头编号说明字误导进成片）、ROUTE-1（穿场景 / 追逐 / 长距离移动没 route map，或成片不按红线走，或把红线箭头生成进画面）。
- **本地硬项（不编号）**：多人物串脸 / 同脸 / 身份漂移、单人镜头凭空分身；主体或关键动作穿模 / 悬空 / 脚不落地 / 手没握住道具 / 重力受力方向错 / 遮挡层级严重错；关键镜头质感塌陷只剩锐化高清、写实真人像磨皮蜡像；违反 `style_contract`（写实片出现动漫脸 / 二次元眼 / 卡通背景 / 游戏 CG / 玩具 3D / 插画质感）。
- **修复方案**：FIX-1（终审问题预设"已通过 / 已接受 / 已修复"诱导放行，或只裁短 / 加转场 / 调色而结构问题没从根上解决）。

## 04 专项审查卡

命中某类题材或某类问题时，在 02 的场景卡之外再叠加这里的专项卡深审。

### 故事和莫名镜头（MAIN / INFO）
直接问：
这个镜头为什么现在出现？
它让第一次观看的观众多知道了什么？

答不上来，不能因为画面好看放行。
修复回编导：补叙事动机、改成信息镜头，或删掉。

### 画面文字（TXT / CU）
编导设计并画进画面的片名、剧名卡、人名牌、章节标题、时间卡、地点卡、关键概念短卡，逐处核三件事：
- 内容逐字正确清晰，没有乱码、截断、冲出画面。
- 出现 / 消散时机和动效按 plan 执行。
- 样式与全片统一。

承载文字的特写重点审：
表盘、屏幕、手机、纸条、合同、名片、书页、招牌、按钮、UI。
只要 plan 让观众看清，就核对是否真的有字、逐字内容是否一致、是否清晰可读。
缺字、糊字、假字、留空，直接不通过。
指出文字问题时不要只写"有乱码"。
必须尽量定位到具体段落、时间附近、画面区域、文字载体和应读内容；如果是广告 logo、slogan、CTA、产品名、时间地点卡或操作 UI，说明它承担了什么信息。
修复建议优先指向该文字载体本身：补清晰局部特写、清晰落版、简化短文字或重做对应 UI / 包装参考，再重做受影响镜头。
旁白可以作为信息冗余，但不能替代对画面文字可读性的审查；plan 要画面可读，就按画面可读审，文字不清晰时仍要要求修复。

复杂叙事还要审文字路标覆盖率。
3 个及以上 segment，至少一半 segment 应有时间、地点、身份、章节、关键概念等文字支架。
少于覆盖率，或无文字 segment 没有合理不上字理由，不通过。

### 白底和特写光线（BG / CU）
参考素材白底是正确设定，不打回。
角色卡、道具图、场景参考、关键帧参考、特写参考可以用白底 / 干净中性底锁一致性。

真正要审的是成片：
- 是否把白底、纯色底、棚拍干净背景带进成片镜头。
- 主体是否悬空无环境。
- 环境层、光源、影调是否由提示编译环节按本场戏重建。
- 特写是否继承所在场景光照。

夜戏特写突然均匀白光、暖调场景特写突然冷白棚拍、脸 / 手 / 道具特写背景漂成纯白，都是问题。

### 镜头语言（CAM / SPACE）
对照 `director_plan` 审：
- 景别、明确视角类型、机位、运镜方向和速度、稳定度是否拍出来。
- 焦距 / 光圈数字是否被继承；plan 写 `24mm、f/8`、`85mm、f/1.4` 这类参数，成片 prompt / 审查要求不能只剩"广角 / 特写 / 浅景深"。
- 第一人称、过肩、无人机、物体内部视角等是否被拍成普通正面机位。
- 焦点、景深、前景遮挡、焦点转移是否服务信息。
- 光线是否符合故事时间和来源：太阳、月光、窗光、灯笼、屏幕光方向不能乱。
- 主体朝向、运动方向、人物左右关系、进出房间方向是否前后自洽。
- 人物与场景比例是否符合叙事：荒漠 / 城市 / 巨型建筑 / 战场等大尺度镜头，若 plan 要孤独、压迫、渺小，人物不应占满画面；情绪特写和关键道具特写才应让主体占大。

镜头语言要看多样性。
全片如果大量段落都用同一种运镜、同一种切法、同一种正面中景对切，按镜头语言单调记问题。

plan 点名标志性镜头时逐个核：
- 希区柯克变焦：主体大小基本不变，背景透视被拉伸 / 压缩。普通推镜不算。
- 昆汀后备箱视角：从容器内部向上，洞口边框可见。普通仰拍不算。
- 诺兰时间停滞：元素凝滞 / 局部静止 / 时间错层。完全常速不算。
- 斯皮尔伯格敬畏推镜：稳定推近被震撼击中的脸，反打或后景揭示他看到的东西。

plan 没要求的朴素镜头不要因为不花哨打回。
只拦"该多样却单调"和"点名了却没做出来"。

### 段内时间轴变化（TIME）
审视频 prompt 时先看有没有段内时间轴，而不是只问成片有没有做出几个动作。

必须逐项核：
- `director_plan` 是否为本段给了粗时间轴；若本段有动作、表情、道具、环境、光影、镜头或声音变化却完全没拆，根因在编导。
- prompt 是否按本段时长拆成 3-6 个阶段，覆盖从开头到结尾；不是只写"前段 / 中段 / 后段"空标签。
- 每个阶段是否同时写主体动作 / 位置、表情推进、道具状态、副主体随动、环境变化、镜头或焦点变化、声音节点。
- 是否只写了动作链，例如"走近→夹起→入口→点头"；这种缺表情过程、道具状态、副主体和环境响应，按 TIME-1 打回。
- 若是静态或慢镜头，也要写清细微变化：呼吸、视线、手指、衣褶、蒸汽、光斑、环境人流或焦点变化。

成片审查时再对照时间轴看：关键阶段是否存在，变化是否突兀跳步，表情 / 道具 / 副主体 / 环境是否像按同一个物理时间在运动。

### 为贴合故事板乱切（CUT）
警惕症状：
一段十几秒的视频里，切到大特写、切到中景、再切大特写、再切中近景，硬切好多刀。
每刀都短促，像在逐格对故事板。

判断：
- 对照 `director_plan` 镜头节拍表，这段到底定了几个镜头。
- 如果 plan 要一个连续长镜头或两三个镜头，成片却切成和故事板格数相等的一堆碎切，就是 CUT-1。
- 看切点是否有戏剧需要：换信息、换焦点、换视角、换情绪节拍才切。
- 纯粹为了逐格对故事板而切，就是乱切。

修复回提示编译环节：按 `director_plan` 定的镜头数重编译。
plan 本来设计成快切蒙太奇的，切得多是对的，别误伤。

### 情绪表演（EMO）
不要只看有没有哭、笑、愤怒。
看情绪因果和过程：
- 上一秒什么信息触发了人物。
- 表情是先僵住、躲开视线、眼睑变重、嘴角抿紧、呼吸断掉，还是直接跳到大哭。
- 脸部、身体、手部细节是否跟情绪方向一致。

情绪结果很强但没有触发、没有逐步变化、细节对不上，就按表演 / 叙事问题处理。

### 质感四层（TEX）
质感不等于高清锐利。
按四层看：
- **环境层**：空气悬浮物、雾、烟、尘、雨丝、湿度、体积光、空气透视、远近层次。
- **镜头层**：感光颗粒、景深、焦点、镜头眩光、bloom / halation、运动模糊、前景遮挡。
- **材质层**：皮肤、布料、金属、木石、玻璃、水、纸张的反射、吸光、透光、粗糙度、磨损、油光、接触面和尺度。
- **显影层**：色彩、阴影密度、明暗对比、饱和度、黑位、高光是否统一。

关键镜头只有锐化和高清，没有空气、光学、材质和显影逻辑，不能算真正有质感。

### 穿帮和物理规律（PHYS / PROP）
图像和视频都要主动查穿帮，视频更要看开头、中段、结尾和动作接触瞬间。

必查：
- **空间连续性**：人物、道具、门窗、桌椅、道路、地平线、室内外关系是否自洽。
- **接触与支撑**：脚是否踩地，手是否握住杯子 / 剑 / 方向盘，坐下是否被椅子支撑。
- **重力与受力**：跳跃、坠落、碰撞、奔跑、推拉、开门、抛物、液体飞溅是否有方向和反馈。
- **生活物理 / 本能反应（PHYS-1）**：酱汁 / 油脂是否会挂边、拉丝、滴落并留下痕迹；杯碗液体是否会晃、减少、沿壁移动；热汤 / 热食是否有蒸汽，人物是否先吹、试探小口、停顿避烫；大块食物是否分口咬断和咀嚼，不能一口吞；湿滑 / 重 / 锋利物是否有调整握法、发力、躲避、眨眼、缩肩或挡脸。
- **对象处理方式（USE-1）**：该用筷子 / 勺子 / 刀叉 / 吸管 / 手套 / 夹子的对象，不能被徒手随便拿；热汤应啜，小酒 / 浓咖啡多抿，浓稠饮品可嘬，矿泉水可大口喝；刺身轻嚼、大块肉咬断分口、布丁奶冻偏抿和含化，不能全都一口吞。
- **遮挡与层级**：手臂穿过身体、衣服穿过椅背、人物从墙里长出、道具前后层级乱跳。
- **身体结构与动作链**：手指数量、关节方向、四肢连接、头颈比例、步态、跑跳落地。
- **道具与服化道连续**：关键道具、伤口、污渍、品牌标识、屏幕内容是否前后一致。
- **AI 常见穿帮**：脸部漂移、手部融化、边缘拉丝、主体背景粘连、影子方向乱、倒影多出人物、文字贴片跟随错误。

主体或关键动作上的穿帮，不放过。生活物理不成立也算穿帮：观众未必说得出规则 ID，但会本能觉得假。

## 05 修复回流规则

审查不是打分结束。
发现问题后走闭环：

`发现问题 → 整理修复计划 → 判断根因环节 → 选择修法 → 重做 → 复审`

重做几乎从来不是把同一句 prompt 再跑一遍碰运气。
要让问题回流到出问题的那一环。

常见回流：
- **回编导**：主线不清、段间承接状态错、走位 / 朝向 / 视角没定、人物与环境尺度没定、道具持有链断、故事板新增未注册资产、莫名镜头没动机、场景多视角或场景运动轨迹图缺失。
- **回素材**：角色卡画错、场景参考包缺失、道具参考不一致、关键特写参考没字或结构错。
- **回提示编译环节**：prompt 漏了环境光照、空间方向、逐字文字、情绪链路、焦距 / 光圈数字、人物与场景构图比例、标志性镜头机械动作、故事板职责、参考绑定表或红线运动轨迹语义。
- **回合成 / 剪辑**：素材本身对，但切点、转场、节奏、顺序或版本选择错。

文字乱码的回流不要默认"整段重抽"。
先看坏的是文字设计、文字载体素材、PE 编译遗漏，还是视频生成时的局部可读性失败：
- plan 没写逐字内容或文字太长太复杂，回编导重设短文字和出现节拍。
- 承载文字的屏幕 / 包装 / logo / UI 没有清晰参考，回素材补局部特写或落版参考。
- prompt 没写逐字内容、位置、样式和可读性，回提示编译环节重写。
- 只有某一小块生成糊了，围绕该块重做受影响镜头；不要换掉无关镜头或改动整片结构。

### 缺实体：不是重编译，是先补 plan + 补资产（FIX）
有一类打回特别容易被误当成"再重抽一次就好"：
**这段戏语义上需要某个人物 / 道具 / 场景，但 plan 里根本没登记、也没生成过对应参考资产。**

典型：审查发现"开场要两人对峙，成片却只有一个人"，或"这里该有把钥匙的特写，画面里根本没这把钥匙"。
一查资产，第二个人没有角色卡，那把钥匙没进道具清单。
故事板里临时画出来的杯子、手表、路人、车辆、屏幕等同理：只要 plan 和资产清单没有登记，就按缺实体处理，而不是默认通过故事板引入。

这不是 prompt 写漏了，是上游缺规划。回流必须走完整三步，不能只丢回提示编译环节改 prompt：
1. **回编导补 plan**：把这个实体登记进 `assets_needed`（REF-1），补它出现的 beat、和已有人物 / 道具的站位与承接关系。
2. **回素材补资产**：真正生成这个实体的参考图（角色卡 / 道具图 / 场景多视角），过审。
3. **再回提示编译环节重编译**：用新过审的资产重新编译本段。

绝不接受提示编译环节在 prompt 里凭空描一个没有角色卡的人、造一把没设计过的道具——那必然串脸、必然和后续段对不上。
复审时先确认那个实体的参考资产是否真的做出来了、是否进了 plan，再看成片。

给修复建议时必须指明：
- 回哪一环。
- 改哪一小块。
- 为什么这个修法能解决根因。
- 修完后用什么证据复审。

### 可以先画纠正图（图 + 文字配套）
问题是空间、走位、视角、人物关系、位置、遮挡层级这类说不如画的东西时，鼓励先生成一张带标注的纠正图。

做法：
- 在关键帧或简化场景图上画 blocking 标记、动作方向箭头、机位标记。
- 标出人物应从画面左走到右、A 站左 B 站右、视线交汇在中央、镜头从哪侧看、门内门外谁在。
- **纠正图要和文字说明配套一起给下游**，不是二选一：图锁空间站位和运动路线，文字把图里的关系逐句写清（谁在左、谁从哪进、视线在哪交汇、谁前谁后）并点明"按参考图站位生成"。
- 把这套图 + 文字作为 img2img / 图生视频 / 下一段首帧 / 构图参考。

注意：
动作方向箭头、blocking 标记、机位标记只用于下游参考，绝不能出现在最终成片画面里。

### 版本和上限
- 个别局部瑕疵，可以把上一版当参考，只改点名那处。
- 整体跑偏，才换思路重做。
- 每次重做另存新版本，别覆盖原文件。
- 同一问题反复几轮过不了，就记录残留问题和取舍，交用户判断，别无限循环。

复审必须逐条对照修复计划。
不要笼统问"现在通过吗"。

## 06 反例库（真实事故，别重犯）
每条只记"踩过的坑 + 正解"，判据本身见对应专项卡 / 场景卡。
- **STB-1｜只审形式不审流动**：格数、手绘、箭头、角色继承都过，没人问连起来能否看懂剧情。正解：形式审完把它当无声小连环画读一遍。
- **CUT-1｜故事板格数绑架成片切镜**：九格被拍成九刀碎切。正解：成片镜头数看 `director_plan`，不看故事板格数。
- **BG-1｜把参考白底当成成片背景**：参考图白底对，成片也跟着白底 / 棚拍光。正解：只打回成片没建环境光照，不打回参考图白底。
- **CU-1｜特写没有字**：屏幕 / 纸条 / 名片 / 合同特写糊成假字还被当"质量还行"放行。正解：承载文字的特写逐字核，不清楚不通过。
- **TXT-1｜乱码不定位就修**：终审说"屏幕文字乱码"，修复只写"重新生成、文字清晰"，没说哪段 / 哪个屏 / 应读什么。正解：先定位坏字载体和信息功能，再补清晰局部特写 / 落版 / UI 参考，复审逐字核。
- **MAIN-1｜盲看说不出故事**：逐段都漂亮，拼成整片只能描述一串画面。正解：终审必做一句话主线盲看复述。
- **CONT-1｜跨段瞬移**：上一段人物走远，下一段无过渡贴脸；上一段出门，下一段背景又回室内墙。正解：滑窗审最后一帧和第一帧并排比。
- **CHAIN-1｜链式生成没接上**：链式延展子段只写"承接上一段"，没用上一段终版作真实参考，成片姿态 / 机位 / 光线 / 道具全重置。正解：查生成记录有无上一段终版参考，没有就回提示编译重编译重生。
- **PROP-1｜关键物品自己流动**：伞 / 钥匙 / 信 / 刀 / 手机无交接换手或状态重置。正解：沿 segment 追踪持有者、位置、状态。
- **TIME-1｜只审有没有动作，不审动作怎么展开**：只问"有没有夹起 / 入口 / 享受"，不看 prompt 有没有分阶段变化和道具 / 蒸汽 / 焦点随动。正解：先查时间轴证据，再看成片是否按时间轴完成变化。
- **FIX-1｜重做只是碰运气**：问题根在 plan，却把同一句 prompt 又跑一遍。正解：回根因环节改对，再重编译和复审。
- **FIX-1｜缺实体当成 prompt 漏写**：审查判"开场没拍出两人对峙"，下游只在 prompt 补一句"对面有个人"就重抽，第二个人根本没角色卡。正解：走缺实体三步（补 plan + 补资产 + 重编译，见 05），空间站位另配纠正图，复审先查资产是否真做出来。
