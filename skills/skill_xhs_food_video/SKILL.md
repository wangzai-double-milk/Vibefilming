- **我负责**：把研究报告转成项目可用的 `research_brief`：结构、时长、钩子、镜头节奏、光线、调色、声音、标题、标签、封面、平台避坑。

- **输出**：一份可被主流程消费的研究摘要，写进项目 brief、script notes 或 director_plan 的 `research_constraints`。

## 一、两份报告的核心结论

两份报告共同指向同一条原则：
**小红书美食/探店视频不是“拍得高级”就够，而是要在短时间里完成：停下 → 馋到 → 相信 → 收藏/行动。**

### 1. 爆款视频拍摄方法研究报告
覆盖探店、美食、旅游三类内容，提炼出跨品类硬规则：
- 竖屏 `9:16` 是默认画幅。
- 前 3 秒必须给钩子，禁止自我介绍、品牌 logo、慢铺环境。
- 探店控制在 `30-60 秒`，美食控制在 `15-45 秒`，旅游 `1-3 分钟`。
- 美食/探店首选侧逆光或窗边自然光，突出食物质感和食欲。
- 镜头节奏为 `1.5-3 秒` 一个信息点，避免一镜到底。
- 景别递进：远景 / 门头 → 中景 / 环境 → 近景 / 餐具细节 → 特写 / 食物纹理。
- 美食必须有动态词和真实物理：冒热气、拉丝、爆汁、淋酱、夹起、油光。
- 环境原声和 ASMR 很重要，咀嚼、煎炸、倒饮料、餐具碰撞声保留 `15%-20%`。
- 发布端必须考虑标题、封面、标签、POI，而不是只产视频。

### 2. 美食博主视频实拍分析报告
从真实小红书样本反推四种可复用风格：
- **教程型**：15-30 秒，强实用，标题“场景 + 食材 + 口感 + 情绪”，收藏价值高。
- **治愈型**：1.5-2.5 分钟，暖调自然光，完整厨房/店内场景，靠情绪价值和场景舒适感。
- **沉浸式**：约 1 分钟，第一视角，ASMR 环境音为主，文案极简，靠独处/夜宵/仪式感。
- **颜值型**：约 30 秒，高饱和色彩和颜色反差，热门 BGM，标题和标签更密集。

评论区反推用户最在意：
- 颜色 / 视觉冲击。
- BGM 和声音记忆。
- 场景布置是否舒服。
- 可复制性。
- 口感描述是否具体。
- 健康 / 热量 / 价格等实用信息。

## 二、探店视频默认结构（30-60 秒）

若用户没有另行指定，小红书探店视频默认按四段式：

| 时间 | 功能 | 必须出现 |
|---|---|---|
| `0-3s` | 黄金钩子 | 最诱人食物特写、拉丝/爆汁/冒热气，或反差问题；不自我介绍 |
| `3-15s` | 环境氛围 | 门头、动线、人气、座位、灯光、局部装修；用局部特写代替大段空镜 |
| `15-45s` | 核心测评 | 食物三镜头：全景上桌 → 微距细节 → 入口互动；微距细节必须先有关键特写素材，口播用通感比喻 |
| `45-60s` | 干货闭环 | 优点、1-2 个小缺点、人均/价格、适合人群、预约/错峰/收藏建议 |

探店不是纯广告。必须保留轻微主观和小缺点，例如“排队久但值得”“座位少，建议错峰”，这样才可信。

## 三、镜头和 PE 约束

### 镜头节奏
- 每 `1.5-3s` 必须有新的信息点或景别变化。
- 可以快切，但不能碎到看不清食物。
- 关键诱惑点可以慢动作：酱汁落下、夹起拉丝、汤面热气、咬开爆汁、筷子夹起。
- 食材 / 菜品的微距细节镜头必须走 CU-3：先基于原菜品、原锅 / 原盘、当前状态和所在桌面光线生成食材切面、油脂纹理、酱汁挂边、拉丝、爆汁、热汤表面、烤痕等关键特写素材，再绑定进视频；不能只从上桌全景里硬拉近，也不能凭空生成一张像另一盘菜的微距图。

### 光线和画面
- 美食/探店优先侧逆光、窗边自然光、侧前方补光。
- 避免顶光死黑和影棚白光。
- 食物多用 45 度角或低角度特写，显立体、显层次。
- 人物出镜可略高于眼睛俯拍，但不能磨皮成假人。

### 生活物理（必须和 PHYS-1 对齐）
- 酱汁会挂边、滴落、拉丝，不能像贴图固定。
- 热汤 / 热食会冒蒸汽，人物先吹、闻、小口试，不直接大口吞。
- 大块食物要分口咬断，咀嚼和吞咽需要时间。
- 杯壁水珠、碗里汤面、油光、高光要随动作变化。
- 处理方式必须和食物 / 饮品匹配（USE-1）：刺身可筷子夹起轻嚼，鳗鱼 / 厚肉要咬断分口，汤羹用勺舀起吹凉小口啜，浓稠饮品用吸管嘬，咖啡 / 小酒可抿，不能所有东西都手拿或一口吞。

### 声音
- 环境原声保留 `15%-20%`：滋滋声、餐具碰撞、咀嚼、倒饮料、店内背景。
- BGM 服务节奏，开头可卡点，中段降低不抢口播。
- 沉浸式可以环境音为主，BGM 为辅。

## 四、标题、封面、标签和发布

### 标题公式
- 探店：`数字/人群 + 痛点/反差 + 结果`
  - 例：`打工人午餐！30元吃出日料感，这家藏太深`
- 教程型：`场景锚定丨食材 + 口感 + 情绪`
- 治愈型：`品牌前缀 + 食物组合 + 饮品`
- 沉浸型：`身份 + 风格词 + 做 + 豪华版 + 食物`
- 颜值型：`季节 + 品类 + 食材 + 感官词 × 3`

标题避免静态地址描述，多用动态方位和结果词：
- 不够：`某某路日料店探店`
- 更好：`巷子拐角这家日料，50元吃到发光`

### 封面
- 单张最具冲击力画面：拉丝、爆汁、冒热气、满桌、入口表情。
- 大字报短句：`会爆浆`、`劝你错峰来`、`人均50吃撑`。
- 可用门框、窗框、吧台、锅沿做天然画框。

### 标签和 POI
默认组合：
`#城市美食 #城市探店 #细分品类 #具体店名 #沉浸式探店 #美食日常`

探店必须给 POI / 地理位置建议；如果成片不发布，也要在交付信息里保留店名、人均、适合人群、预约建议。

```text
research_brief:
  platform: 小红书
  content_type: 探店 | 美食 | 旅游 | 混合
  aspect_ratio: 9:16
  target_duration: <例如 60s>
  source_reports:
    - 爆款视频拍摄方法研究报告.md: <已读完整 / 核心引用>
    - 美食博主视频实拍分析报告.md: <已读完整 / 核心引用>
  structure:
    - 0-3s: <钩子>
    - 3-15s: <环境氛围>
    - 15-45s: <核心测评>
    - 45-60s: <干货闭环>
  visual_rules:
    - 竖屏9:16
    - 侧逆光 / 窗边自然光
    - 1.5-3s 一个信息点
    - 远景→中景→近景→特写
  food_rules:
    - 冒热气 / 拉丝 / 爆汁 / 淋酱 / 夹起 / 油光
    - USE-1: 按对象写筷子夹 / 勺子舀 / 吸管嘬 / 杯沿喝 / 抿 / 啜 / 咬断 / 咀嚼 / 含化

    - CU-3: 食材切面 / 油脂纹理 / 酱汁挂边 / 拉丝爆汁等微距镜头必须有单独关键特写素材，且特写要继承原菜品、原状态和原场景光线
  audio_rules:
    - 环境原声15%-20%
    - ASMR声：咀嚼/煎炸/倒饮料/餐具碰撞
    - BGM不抢口播
  publishing:
    title_formula: <标题公式>
    cover: <封面画面 + 大字报>
    tags: <标签组合>
    poi: <是否需要>
```

## 六、审查清单

交付给主流程前自查：
- 是否完整读完用户给的报告，而不是只读前半。
- 是否明确选择探店 / 美食 / 旅游 / 混合类型。
- 是否保留 `0-3s` 钩子，且没有自我介绍。
- 是否有食物动态和生活物理。
- 是否有环境原声 / ASMR / BGM 策略。
- 是否有干货闭环：优缺点、人均、适合人群、行动建议。
- 是否给标题、封面、标签、POI。
- 是否把 `research_brief` 写进项目状态源或交给 director_plan 消费。
