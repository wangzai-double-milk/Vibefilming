# Skill · 广告策略

## 职责

把 brief 变成清楚的商业方向：

- 卖给谁或吸引哪类玩家。
- 前三秒靠什么停住用户。
- 核心价值靠什么被看见和相信。
- 用户看完应采取什么行动。
- 哪些事实已确认，哪些只是广告表现。

不写流程状态、JSON 字段、镜头参数或生成提示词。

## 游戏广告

先判断任务属于：

- **剧情前贴**：困境或欲望必须与后续游戏内容有关，钩子不能与玩法脱节。
- **固定逻辑换皮**：可以换已授权美术，但保留人物职能、事件因果和反转顺序。
- **玩法转绘**：优先证明操作、反馈、资源变化和升级是否读得懂；先做代表段，不以单条成功推断批量稳定。

游戏前三秒优先展示目标、危机、可操作对象或结果反差。参考广告呈现的玩法不自动等于目标游戏的真实功能；未经确认不得写玩家数、福利、无广告或投放成绩。

变体一次只改用户指定的变量。用户只换场景时不改人物，只换人物时不改场景；不借优化钩子、美术、压力或CTA擅自扩大范围。没有明确改剧情授权时，原动作、数量关系、操作顺序、文字与声音均保留。

## 电商与品牌

进入制作前明确：

- 核心人群和使用情境。
- 产品身份及允许表达的卖点。
- 演示、同条件对比、成分工艺、资质或体验中的可信证明。
- 点击、进直播间、领取权益、下单或品牌记忆等行动。

效果广告尽早建立产品身份，每一段都推进痛点、产品、证明或行动。表现可以夸张，产品身份、事实和对比条件不能造假。品牌广告可放慢节奏，但必须留下明确品牌记忆。

## 资产与事实

- 游戏使用用户提供的游戏画面、角色、建筑、地图和 UI 作为真实性来源。
- 商品使用用户提供的产品图、包装、Logo 和已确认卖点作为真实性来源。
- 跨品牌复刻只借结构和节奏，不复制不该继承的品牌资产。
- 独立新片不复用用户未授权的旧项目素材。

## 选型经验

- 生存建造适合“危机 → 收集 → 投入 → 环境改善 → 新压力”。
- 采集经营适合“采集 → 加工 → 售卖 → 升级 → 自动化”。
- 合并消除适合“目标 → 选择对象 → 合并或消除 → 交付 → 新目标”。
- 战斗塔防适合“敌群压力 → 攻击 → 掉落 → 建塔或强化 → 反击”。
- 剧情加玩法必须让人物困境通过玩法得到改善或反转，不能简单拼接两条片。

这些只是结构经验，不是产品功能事实。每条素材只选择一条核心循环，避免把多个玩法塞进短时长。

## 常见 bad case

- 开场只讲世界观，前三秒没有目标、危机或产品身份。
- 参考广告有某玩法，就直接宣称目标游戏也有。
- 为追求爽感重复领奖、凭空升级或改变规则。
- 多版本同时改钩子、玩法、美术和 CTA，最后无法判断哪个变量有效。
- 以曝光量、模型评分或单条成功样片代替真实转化数据。

## 输出

只输出简洁的广告决策：

1. 广告类型与目标受众。
2. 一句话钩子和核心价值。
3. 可信事实与禁止编造项。
4. 建议验证的最小版本。
5. 变体时唯一改变的主变量。
