# Skill · 广告创作（商业镜片，套在主影视产线上）

## 执行卡
- **何时读我**：用户需求带商业目的时：卖货、投流、品牌曝光、种草、带货口播、TVC、出海素材。
- **我负责**：把 Brief、Hook、痛点、产品证明、CTA、品牌记忆和转化目标注入主流程。
- **我不负责**：另起一条广告产线；具体剧本、编导、素材、生成、审查细则仍回对应阶段规则。
- **输入**：商业 Brief、产品 / 品牌资产、目标人群、投放平台、转化目标、已有爆款或品牌规范。
- **输出**：可进入主流程的商业判断：广告类型、卖点演绎、转化漏斗、资产复用、变体策略。
- **失败回流**：卖点不清、Hook 弱、CTA 不明、品牌资产漂移时，回本层先校准商业策略。

## 红线速查

广告规则是本阶段的商业判断，不另起编号体系。

| 红线（出现即错） | 正解 |
|---|---|
| 把广告当普通剧情片，只追求好看 | 结构服务停下、相信、行动 |
| 起点是灵感，不是商业 Brief | 先判目标、受众、卖点、转化动作 |
| 前 3 秒没有视觉钩子 | Hook 前置，痛点或反差必须可见 |
| 产品、Logo、包装、模特、品牌版式只靠文字描述 | 品牌资产必须作为真实参考参与生成 |
| 多版本每条重新发明产品 / 人物 / 音乐 | 同一 campaign 复用统一品牌资产 |
| CTA、品牌落版、标语当整段字幕烧录 | 作为画面文字短标识走编导 / 提示编译 / 审查规则 |

> **何时读我**：用户的需求带有商业目的（卖货、投流、品牌曝光、种草、带货口播、出海素材）时，用我先做"广告脑"，把商业目标转成可执行的内容方向。
> **核心信念**：广告的第一性原理是「用内容给消费者创造意义感」。一条成功广告的本质任务 = **吸引注意力 → 激发兴趣 → 驱动商业转化**。

## 〇、我是补充，不是另一条产线（先认清边界）

广告片**不另走一套流程**——它和普通影片一样，走剧本、编导、素材、拍摄、合成、审查这条主骨架。每个阶段"怎么落地"看该阶段本身的规则，我不重复定义：

- 剧本怎么写、人设怎么立、**剧本必须落盘** → 看剧本阶段规则。
- 分镜节拍、段间衔接、转场、故事板规划、**画面内文字（含品牌落版/CTA/标题这类标识文字）怎么出**、音频计划 → 看编导方案。
- 三视图、道具、场景、风格锚点、**品牌资产怎么锁定、角色与产品一致性** → 看素材阶段和 `director_plan` 的资产规划。
- 阶段闸门、状态真相源、合成 → 看主流程规则。
- 通过/不通过标准、终审 → 看审查标准。

**我只做一件别人不做的事：把"商业判断"注入到这条骨架的每个阶段里**——起点是 Brief 而非故事创意，验收看转化而非美感，结构按转化漏斗而非起承转合。凡是"具体怎么做"的细节，一律回到对应阶段规则，不在我这里另立一份。

## 一、广告脑往主流程每个阶段注入什么

| 主流程阶段 | 该阶段"怎么做"看哪里 | 广告脑在这里要注入的商业判断 |
|---|---|---|
| **剧本阶段** | 剧本阶段规则 | 起点是商业 Brief；卖点要演绎成微观动作或痛点场景；口播逐字写清；情节服务"停下、相信、行动" |
| **编导阶段** | 编导方案 | 节拍按 Hook → 痛点 → 产品 → 证明 → CTA；前三秒要有视觉钩子；CTA / 落版 / 标语走画面文字规则 |
| **素材阶段** | 素材规划与 `director_plan` | 产品、包装、Logo、模特、服装、场景调性、品牌落版版式都要真实参考；多版本复用同一套品牌资产 |
| **合成/剪辑阶段** | 主流程与剪辑决策 | 是否需要多版本 / 多比例 / 多时长 / 多语种 / 多卖点 A/B 变体 |
| **审查阶段** | 审查标准 | 在通过标准上再加一把商业尺子：钩子拦没拦住人、卖点说没说清、CTA 明不明确、品牌资产有没有漂移 |

## 二、广告策略先定四件事

进主流程之前，先用"广告脑"判断这条广告要靠什么赢，这几条会成为注入各阶段的依据：

1. **资产复用**：是否要继承现有产品图、品牌视觉、模特形象、历史爆款节奏。
2. **音画同步**：是否需要口播、环境声、节奏卡点或品牌音乐参与转化。
3. **商业节奏**：钩子、痛点、产品出场、卖点证明、CTA 的顺序和时长分配。
4. **投放变体**：是否需要多版本、多比例、多语种、多卖点 A/B 测试。

## 三、从 Brief 到可拍方向：先判广告类型

拿到的往往是偏业务目标的 Brief，需要先判类型，再把对应的商业判断注入主流程：

- **品牌广告**：严格锁主体，侧重消费场景、视觉调性、品牌记忆点。
- **效果广告**：视觉钩子前置，痛点外化，卖点证明直白，CTA 明确。
- **创意内容**：先定材质/风格/世界观，再用微小物理交互展示卖点；涉及食物、饮品、工具、产品使用时，必须守 USE-1（手拿/工具拿、抿/嘬/啜/大口喝、咬/嚼/含化要匹配对象）和 PHYS-1（会滴、会晃、会冒热气、会需要吹凉/分口/发力）。
- **口播带货**：口播逐字写清，语速、情绪、产品动作同步（口播文本走剧本和编导方案，不做后期烧录字幕）。
- **爆款复刻**：只复刻结构、节奏、运镜或表演方式，不复制不该继承的人物和品牌资产。

## 四、高优场景最佳实践

### 投流跑量
前 3 秒必有视觉钩子、节奏紧凑、结尾明确 CTA；用换人物/换产品批量出变体。

### 种草卖货
产品展示/替换为主：3C（耳机/相机）、生活用品、户外装备、服装鞋装。强调产品全程清晰不变形、多角度展示、白底或场景化。也含产地溯源（牧场奶源）、产品创意展示。

### 品牌片
注重氛围营造、情绪节奏、视觉美学统一。类型：品牌概念/TVC、品牌 IP 形象延展、品牌故事表达、高奢氛围。创意意识流场景建议用 Vibe Creating 方式。

### 互动带转化
真人扫脸展现真实场景。类型：达人种草、短剧剧情植入、热点借势（citywalk/节日）。强调真实记录感、口播自然、痛点反差。

### 出海素材
- 多语种口播：英/法/美式英语等，口播必须完整自然、语速适配时长、避免书面化过强，不额外生成同文口播字幕。
- 多元面孔：同一产品适配不同肤色/年龄/气质，传递包容自信。
